# 测试体系

测试按“纯逻辑单元 → React 组件 → 后端接口与数据库 → 供应商契约 → 浏览器端到端”分层。低层测试负责快速定位，高层测试只覆盖真实用户链路，避免全部依赖缓慢且不稳定的端到端测试。

## 分层与工具

| 层级 | 工具 | 主要职责 | 执行时机 |
| --- | --- | --- | --- |
| 前端单元 | Vitest + jsdom | Zustand selector、画布几何、端口兼容、消息投影、生成参数解析 | 每次提交 |
| 前端组件 | Testing Library | 卡片自动保存、图片预览、主图操作、Agent 输入框、审批与附件交互 | 每次提交 |
| 后端集成 | Node test + 临时 SQLite | 身份、隔离、revision、文件、任务、Agent、风格和备份 API | 每次提交 |
| 供应商契约 | 本地 HTTP/WS 模拟服务 | OpenAI、Anthropic/New API、Gemini、方舟、ComfyUI 的请求和异常协议 | 每次提交；慢用例夜间执行 |
| 浏览器 E2E | Playwright | 多页面真实交互、断线恢复、关闭页面继续任务、网络不泄露供应商地址 | 合并前关键链路；完整集夜间执行 |
| 手动视觉验收 | 固定示例项目与截图清单 | 画布布局、主题、长对话、拖拽、缩放及媒体体验 | 版本候选 |

## 业务覆盖矩阵

- 画布核心：节点增删改、类型化端口、连接限制、复制粘贴、撤销重做、缩放拖拽、项目 revision 冲突和多标签页刷新。
- 创作资产：角色、场景、道具的创建、自动保存、状态、参考媒体、生成变体、主版本、收藏、节点视图与实体删除边界。
- 视觉风格：模板、自定义描述、参考图、项目默认、局部覆盖、删除回退、生成快照和用户隔离。
- 生成中心：模型能力过滤、引用顺序、队列并发、流式文本、取消、重启恢复、媒体回存和临时 URL 隔离。
- Agent：会话隔离、SSE 快照/增量去重、思考与工具投影、审批追问、附件、资产/风格引用、Skill、服务重启和客户端工具桥。
- AI 服务中心：管理员权限、加密凭据、模型发现、手动模型、连接测试、默认模型和脱敏任务列表。
- 文件与安全：上传、Range、MIME/端口匹配、路径穿越、跨用户文件引用、孤儿清理和供应商信息泄露。
- 备份与迁移：SQLite 一致性快照、SHA-256 清单、损坏拒绝恢复、恢复前快照和浏览器旧数据导入。
- 部署边界：开发代理、Unix Socket/Base Path、fnOS Header 身份以及后续 FPK 验收。

每个业务域至少覆盖成功、输入非法、越权、revision 冲突、网络中断和服务重启六类情况；不适用的情况需要在测试名称或矩阵中明确说明。

## 质量门禁

日常提交必须通过前端测试、前端类型检查、前端生产构建、后端测试和后端 TypeScript 构建。修复线上或验收缺陷时，先写能够失败的回归用例，再提交修复。新增 API 必须包含权限、资源隔离和错误结构测试；新增 React 外部 store selector 必须验证空值和派生值的引用稳定性。

完整 Playwright、多供应商异常矩阵、备份恢复和服务重启场景进入夜间测试。版本候选只有在自动门禁通过、待测试清单完成且关键手动视觉流程确认后才能发布。

## 建设顺序

1. 建立 Vitest、后端临时数据库测试和统一命令，覆盖当前 v0.20 回归。
2. 为画布、创作资产、视觉风格、Agent 和生成中心补齐组件与接口测试。
3. 引入 Playwright，建立小说拆解到资产设计图的关键用户旅程。
4. 建立供应商协议模拟器、服务重启夹具和 WebDAV 故障夹具。
5. 接入 CI：提交快速集、合并关键 E2E、夜间完整集，并输出覆盖率与失败产物。
