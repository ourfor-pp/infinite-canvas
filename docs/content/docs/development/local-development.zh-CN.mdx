# 本地开发

项目由 `web/` 下的 Vite 前端和 `server/` 下的 Express 服务组成。

## 1. 同时启动服务

```bash
./dev.sh
```

前端默认访问：

```text
http://localhost:3000
```

## 2. 配置模型

开发模式用户默认拥有管理员权限。打开右上角「AI 服务」配置公网供应商、加密凭据、模型能力和内网 ComfyUI 节点；WebDAV 快照仍在配置页的「服务与备份」中管理。

## 3. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改 REST、WebSocket、SQLite、文件和后台生成：主要看 `server/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
