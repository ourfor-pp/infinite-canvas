# Local Development

The application uses the Vite frontend in `web/` and the Express service in `server/`.

## Start both services

```bash
./dev.sh
```

Open `http://localhost:3000`. Vite proxies `/api` and `/api/events` to Express on port 3001. Development users are administrators by default and configure public providers, credentials, model capabilities, and ComfyUI nodes under AI Services. All model calls and WebDAV snapshots run on the backend.

## Start the documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- REST, WebSocket, SQLite, files, and background generation: `server/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
