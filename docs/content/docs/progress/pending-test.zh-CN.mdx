# 待测试

- 节点双击聚焦：双击任意节点只改变画布视口，不修改节点尺寸、位置和连线；普通节点应尽量填满扣除工具栏后的可用区域，图片等带下方编辑框的节点需把节点和编辑框整体完整放入，角色／场景／道具聚焦动画完成后打开调图浮层。
- v0.22 创作 Skill：小说拆解只提交可编辑的角色、场景、道具候选，不得创建风格或媒体任务；角色、场景和道具设计必须保存调图面板可见、可编辑的生图补充提示词，且不重复资产描述、固定设计图版式或项目风格；跨多类资产的请求必须调用相应领域 Skill，遍历用户要求范围内的全部资产并补齐场景环境声、道具音效、角色声音和试听台词，不得完成角色后遗漏其他类型。
- 角色设计一致性：明确或未知性别、年龄时都要建立内部设计档案，不得根据名字猜测；明显冲突的声音性别必须在生成前阻止，角色描述只包含长期稳定、可被画出的特征，不得混入剧情、性格或关系。
- 干净设计图：角色和道具使用纯白背景，场景不得出现人物，所有设计图禁止文字、水印、标志、界面和剧情动作；需要检查时由用户让 Agent 针对当前结果给出可执行的重生成修改点。
- 视觉风格卡：上传来源图，分析为 Style DNA，生成角色、场景、道具三张中性样张，编辑并确认风格后设为项目默认；草稿风格不能成为默认，资产生成前必须由用户明确确认是否继续使用。
- 视觉风格引导：创作资产调图面板必须显示局部连接／项目默认、草稿／已确认或未配置状态；点击配置或创建应关闭媒体浮层并定位到对应风格卡，首个确认风格自动成为项目默认，新建草稿风格不得误报失败或重复创建。
- 模型参考能力：配置图片参考语义和最大参考数，验证风格、上传主体、画布连线和当前主图按顺序去重、按能力过滤，并冻结到生成任务快照。
- 图片模型能力与场景工作流分离：在供应商的每个图片模型配置中选择“文生图 / 图生图”，勾选图生图后必须设置最多参考图数量，不再提供主体、风格、构图等参考图语义开关；调用方案只能约束可选能力，保存后不得重新推断覆盖。普通图片请求无参考图时校验文生图，有参考图时校验图生图并拒绝超限引用。局部编辑、忠实超分、细节增强和多角度必须标记为专用工作流，在「模型与生成」中显示可用状态与启停开关。
- v0.16 本地图片工作流：验证 Qwen Image 2512 的 Lightning 4/8 步与无 Lightning 40 步、Z-Image Turbo、Qwen Edit 2511 的 1 至 3 张参考图和 HiDream 覆盖全部画布比例；结果不能被固定成 16:9，缺节点或模型时必须返回稳定错误且不得回退。
- v0.16 局部编辑：覆盖人物、物体替换、材质替换和文字区域，分别验证严格保留与自然融合；严格模式在扩张与羽化范围外必须逐像素保持不变，刷新或切换项目不得终止后端任务。
- v0.16 AI 超分：对横图、竖图、透明 PNG、人物、产品、UI 和文字图验证忠实超分与细节增强的 1K、2K、4K 输出；结果尺寸必须与预览完全一致且 RTX 5090 不得 OOM。
- v0.16 四视图：至少连续执行三组人物或产品参考图，检查正面、左侧 90°、右侧 90°、背面 180° 的槽位归属、进度、单槽失败、独立重试、下载、设为主图和刷新恢复。
- v0.16 ComfyUI 共享调度：连续排队文生图、编辑、局部编辑、超分、四视图、视频和音频任务，同一 ComfyUI 节点任何时刻只能运行一个任务。
- Agent 对话与输入体验：验证回合分组、思考/工具过程自动展开收起、原位审批追问、流式跟随暂停、历史前插补偿、80 项以上虚拟化、回到底部未读数、局部错误恢复以及浅色/深色蓝白视觉；输入框应支持中文输入法、正文内 Skill/节点/资产/风格原子引用、结构化复制粘贴、附件拖放和会话级持久草稿。
- Agent 完整历史恢复：单轮包含数百个流式增量事件时，刷新页面或重启服务后仍应恢复该轮用户气泡、过程与最终回复；界面不应出现点了无效的“加载更早消息”。
- Agent 用户气泡操作：悬停或聚焦用户消息时应显示圆形复制与“从此消息重新开始”按钮；重新开始必须先确认，再创建仅保留目标消息之前历史的新分支，完整回填原有版本化正文和附件且不自动发送，画布与工作目录文件不得回滚。
- Agent 分支与输入框清理：从用户消息重新开始后，新分支应在原消息位置以无气泡、无图标的淡色小字显示“从这里重新开始”，消息时间也只显示淡色文字且没有两侧横线；不得混入被点击的原用户气泡、后续回复或“任务已取消”状态。修改回填内容并发送成功后，即使输入框仍有焦点也应立即清空正文和附件。
- Agent 分支实时消息：进入新分支并提交后，用户消息、思考、工具过程和最终回复应随服务端事件即时出现；SSE 自动重连后应从 SQLite 权威快照补齐断线期间事件，不得依赖刷新页面。
- Agent 重启中断状态：任务运行或等待确认时重启服务，恢复后应显示明确的 `SERVICE_RESTART_INTERRUPTED` 失败记录，旧的“Agent 已开始处理”不得继续伪装成运行中。
- Agent 运行状态投影：运行中的过程摘要应按“工具调用 · 过程记录 · 思考轮次”展示并保留本轮耗时；底部胶囊不得长期显示瞬时的“Agent 已开始处理”，应跟随最近的思考、工具进度或模型处理中状态，长内容可查看全文。
- Agent 运行中调整与队列：空闲会话使用 direct，运行中“马上发”通过同一个 SDK 输入通道追加到当前 run，“稍后发”按 FIFO 持久排队；幂等重试不能重复创建消息，等待审批时拒绝 steer 但允许排队，失败、取消和服务重启后队列进入 held，用户确认重试/立即发送/删除后附件引用应正确清理。
- Agent Tool Search：Anthropic Messages 渠道默认启用并在对话流显示「搜索可用工具」，OpenAI-compatible/方舟代理默认关闭；`AGENT_ENABLE_TOOL_SEARCH=true|false|auto|auto:N` 可显式覆盖。管理员任务列表应展示每次运行的模式和调用次数，Skill 的 `allowed-tools` 只能合并应用已注册且非破坏性的工具，不能放开 Shell、外网或删除操作。
- 故事创作与 Markdown 文本节点：让 Agent 创作包含标题、多个章节和尾声的故事，故事 Skill 只能创建一个通用文本节点；阅读态应正确渲染标题、段落、强调、列表、引用、链接和代码，双击后可编辑原始 Markdown。续写或修改时应更新原节点，不得重新生成一组章节卡片。
- 自动质量门禁：根目录 `./verify.sh` 应依次通过前端 Vitest、前端 TypeScript、Vite 生产构建、后端集成测试和后端 TypeScript 构建；GitHub 拉取请求及 main 分支推送应执行同一门禁。React 外部 store 空快照、语义端口、视觉风格生命周期、用户隔离和创作资产部分更新均已有回归覆盖。
- 语义端口与风格编排：文字、图片、音频、视觉风格和创作资产端口应拒绝不兼容连接并执行单/多连接限制；项目默认风格、节点局部覆盖、参考图和生成任务快照应正确解析，缺少端口 ID 的旧连接不得读取。
- Agent 交接与图片交互：点击资产或风格的「交给 Agent」应保留草稿、预置可移除引用且不自动发送；角色、场景和道具主设计图点击直接打开调图悬浮编辑器，顶部参考缩略图点击仍只预览，预览期间 Delete/Backspace 不得穿透到画布。
- 共享媒体编辑器：图片、音频基础节点和角色、场景、道具业务卡应共享提示词编辑、模型设置、任务进度、错误与预览；「调图／调声音」通过桌面宽幅、完全不透明的 Portal 浮层打开，不得透出下层卡片，也不得改变节点尺寸、端口和连线位置，关闭浮层或点击画布后已保存草稿仍应保留。
- 媒体草稿与请求预览：图片、音频草稿独立于资产描述持久化；「实际发送预览」和生成记录的请求快照应包含完全一致的最终提示词、模型、参数、风格 revision、连线输入及去重后的参考顺序。revision 冲突、模型禁用、能力不符和参考越权必须在创建任务前阻止。
- 媒体引用与替换：提示词上方显示上传和画布连线参考；输入 `@` 可先看到已连接引用，再展开选择其他画布图片并自动建立语义连线；移除顶部缩略图应同步断线或删除上传引用。业务媒体生成后直接替换当前主图／主音频，不显示候选历史；需要保留旧方案时先复制业务节点，副本必须拥有独立创作资产实体。
- 创作声音语义：角色使用 `speech` 并持久保存音色提示词与试听台词，场景使用 `ambient`，道具使用 `sfx`；模型下拉按声明的 `audioModes` 过滤，未声明的旧音频模型只按 `speech` 处理，缺少环境声或音效模型时必须明确阻止生成。
- 创作业务卡片：从画布底部「业务设定」直接新建角色、场景和道具；每种资产只有一张贴合内容的固定尺寸业务卡，不再存在底部留白、小卡、双击展开、分区切换或尺寸突变。卡片常驻完整横版主设计图、名称、自然语言描述和紧凑的主音频／生成状态；提示词、参考媒体和模型只在对应共享悬浮编辑器中显示。
- 节点编辑与生成：三类资产都只保存一段可见、可画的 `description`，不得再出现性格、关系、人物背景、所属角色或剧情作用等固定表单；图片和音频设置只保存到 `mediaDrafts`。存在未保存草稿时，设计图或声音生成应先保存，且不得用旧草稿覆盖并发生成结果；图片与声音并发生成时应分别显示正确进度。
- 节点删除与资产库：删除单个或多个业务卡片只能走一次后端权威操作，不得误弹“画布已在其他页面更新”；真实冲突时同一项目也最多显示一个弹窗。已收藏到资产库的快照继续保留，重新插入时创建独立业务卡片，不得静默关联原项目实体。
- 小说拆解：让 Agent 拆解被引用的小说文本节点，候选清单应支持改名、取消、换类型、合并重复项，并直接编辑完整视觉描述和角色声音；确认后应在单个事务中创建独立卡片，不得附带持久 Group 节点。角色描述不写性格、关系和剧情背景，场景不写人物和剧情事件，道具不写所属角色和剧情作用。
- 创作设计图与参考：角色设计图固定为横版胸像＋正面／四分之三侧面／背面四格，场景固定为主环境＋局部细节，道具固定为正面／45 度侧面／细节三视图。参考顺序固定为风格主图、上传参考、连线参考、当前主设计图，按 fileId 去重且仅能力匹配的模型可以收到引用；生成快照应记录画布节点、引用标签和文件 ID 的对应关系，文件只使用鉴权 URL。
- 管理员配置：`/admin/ai` 应采用「配置分类 / 供应商列表 / 当前供应商详情」三级主从布局，集中包含供应商、Agent、模型与生成默认值、共享提示词来源、服务备份和运行任务。ComfyUI 应作为本地工作流供应商出现在供应商列表中。供应商编辑使用紧凑居中弹窗，模型列表只显示一次列标题并支持搜索；每个模型绑定后端注册的调用方案，由方案派生输出、输入、请求路径和 Agent 能力。全局默认值应作为所有用户的初始配置，并在对应模型失效后自动清空。
- 后端统一生成：生图、图片编辑、文本多轮与流式输出、视频、语音、画布节点、插件 Host 和 Agent 画布工具均只请求应用 `/api`；浏览器网络面板不得出现供应商域名、Base URL、API Key、Auth Token 或 ComfyUI 节点地址，生成媒体应回存为当前用户的鉴权文件。
- 模型调用方案：分别验证 OpenAI、OpenAI-compatible、Anthropic、Gemini、火山方舟及固定 ComfyUI 工作流的文本、生图、视频和语音方案；应由模型选择的调用方案而非供应商预设决定生成适配器、请求路径、输入校验和 Agent 支持。Anthropic 官方 API、自定义 Base URL、API Key 和 Auth Token 分别可用；New API 域名根地址应自动规范到 `/v1`，通过 `/v1/models` 发现模型并通过 `/v1/messages` 生成，System Prompt、多轮消息、流式文本和图片输入正常。
- 持久任务队列：验证全局、单用户和单渠道并发限制，页面关闭后任务继续，WebSocket 断线后可从 REST 恢复；取消任务应中止本地执行并尽量取消远程任务，服务重启后有远端任务号的视频/ComfyUI 恢复轮询，一次性请求以 `SERVICE_RESTART_INTERRUPTED` 结束且不重复扣费。
- 数据库升级：使用缺少 `error_code` 字段的既有 v0.17 开发数据库重启后端，应自动补齐字段、保留已排队任务，并保持 Express 与 WebSocket 服务在线。
- 用户配置移除：顶部导航和路由不再显示用户配置页或弹窗；缺少模型时普通用户只收到“请管理员配置”的提示，管理员收到前往管理员配置的提示。配置文件导入导出和浏览器本地存储统计不再提供。
- 任务与文件安全：服务端应拒绝能力不匹配、未启用模型和跨用户参考文件；普通模型目录只返回模型 ID、名称、渠道显示名及输入输出能力，任务响应不得包含供应商临时结果 URL，管理员任务列表不得展示提示词、内容或未脱敏错误。
- 前后端开发链路：在根目录执行 `./dev.sh` 后，应复用或启动仅绑定 `127.0.0.1:8189` 的 ComfyUI，同时启动 `127.0.0.1:3001` 的 Express 与 `0.0.0.0:3000` 的 Vite；普通用户页面响应中不得出现 ComfyUI 地址。
- 服务端数据：两个浏览器使用同一开发用户时应看到相同画布、素材、生成记录和配置；以 fnOS Header 模拟两个用户时，项目、素材、文件和任务必须完全隔离；同一画布在两个页面编辑应触发 revision 冲突并允许重新加载或明确覆盖。
- 旧数据导入：空后端检测到旧 IndexedDB 时应提示导入，媒体上传中断或事务失败后旧数据保持原样；成功后刷新应只读服务端数据，重复执行不得生成重复项目或记录。
- 后端 ComfyUI：HiDream 文生图/参考图、H3 首尾帧/多模态参考视频和 VoxCPM2 中文声音设计应通过服务端固定工作流完成；关闭页面后任务继续，重新打开可从 REST 与 WebSocket 看到最终状态和结果，取消、节点错误、离线、超时及服务重启恢复应显示明确状态。
- 管理员备份：管理员可创建、列出及恢复包含 AI 服务配置的 WebDAV 完整快照。损坏清单、哈希不符或 SQLite 完整性失败时不得覆盖当前数据，正常恢复前应自动保留本地安全副本。
- 文件服务：图片、音频和视频上传后应使用鉴权文件 URL；音视频 Range 播放正常，路径穿越和跨用户下载返回拒绝，无引用文件只在延迟清理窗口后删除。
- 项目化 Canvas Agent：普通页面不得存在 Agent 入口或挂载面板；每个画布项目独立保存面板开合、草稿、当前会话、历史、附件和未读状态。同项目两个会话可并发运行，离开画布不得取消任务；重新进入或刷新后，应通过项目 SSE 的全量会话摘要和 REST/eventSeq 快照恢复全部状态，事件不得遗漏或重复。
- Agent 身份与自动权限：不同用户、不同项目的会话、文件、任务、引用、项目规则和工作空间必须隔离。读取、查询、非删除画布编辑、生成、工作区写入与发布、选择、聚焦和项目内导航自动执行；节点/连线/素材/创作资产删除及受保护设定修改分别覆盖 SDK auto 允许、带中文原因的 auto 拒绝和升级人工。人工确认支持「允许一次 / 本会话记住 / 此项目允许」，项目授权只向当前项目 `.claude/settings.local.json` 写入窄规则；`ask_user` 和小说候选确认仍等待业务输入。
- Agent 画布与生成工具：验证 revision 感知的节点读取、新增、更新、连接、删除与冲突处理；Agent 应先读取能力匹配的生成模型，再创建持久任务并查询状态，关联项目和节点的任务应在状态变化及完成后通过 `project.updated` 回写画布；没有活动页面时，导航、选择和聚焦操作应明确返回 `CLIENT_REQUIRED`。
- Agent 项目工作空间、附件、产物与 Skill：同项目全部会话统一使用 `agent/users/<userHash>/projects/<projectHash>/`；附件按 fileId 去重，删除会话保留共享文件，删除项目同时移除文件引用和工作空间。同一路径写入应通过原子替换依次完成，不同路径可并发，发布必须等待对应写入；Skill 通过内容哈希和原子目录替换同步到项目 `.claude/skills`，并发 Run 不得互删文件。
- Agent 存储升级：用包含完整会话、Run 和事件的 storage/protocol v1 数据库升级；启动前必须先生成带 SHA-256 清单的数据库与旧 Agent 目录备份，清空旧 SDK session id，追加明确的上下文重置事件，旧会话目录只留在备份，并把会话文件引用转为项目引用。分别验证成功、未知版本、损坏清单、冲突备份和中途中断重试，任何失败都不得覆盖原数据库或旧 Agent 目录。
- Agent 渠道兼容：测试 Anthropic 官方与 New API Messages，以及 OpenAI、OpenAI-compatible、火山方舟通过后端私有协议代理时的流式文本、思考、工具调用、图片、API Key/Auth Token、429、超时、取消和脱敏错误；Gemini 原生模型不得成为 Agent 模型，浏览器不得看到任何供应商地址或凭据。
- 画布选择与平移：左键点击节点应选中节点，按住拖动应移动节点；左键点击画布空白处应取消选择并收起节点工具条和输入面板，按住空白处拖动应直接平移画布，不再要求 Control。Shift 加空白处拖动应框选多个节点，且虚线在任意缩放比例下保持清晰一致。「移动」工具、中键拖动和 Space 加拖动仍可从空白或节点上平移画布；Ctrl/Cmd/Shift 加节点点击仍可追加选择，输入框和可编辑文本内仍可正常输入空格。
- 文本节点滚动：选中文本节点且正文溢出时，鼠标停在阅读区或编辑区滚轮应直接滚动长文本，不得缩放画布；移出节点后滚轮仍应恢复画布缩放。
- 文档站国际化：访问文档站首页及 `/docs` 应默认显示英文，切换简体中文后 URL 应带 `/zh-CN` 且首页、顶部导航、侧边栏、正文、搜索框和页面操作文案均显示中文；刷新、站内跳转和再次切回 English 后语言应保持正确，搜索结果与 Markdown/LLM 文档内容不得混入另一种语言。
- 国际化基础框架：从页面右上角切换简体中文或 English 后，首页、顶部及移动端导航、版本弹窗、配置主面板、渠道编辑、模型选择、页面标题、页面描述和 Ant Design 内置文案应立即切换，刷新页面后保持所选语言；偏好设置中不应再显示语言选项，WebDAV 同步错误、提示词来源及其他尚未接入翻译的业务模块暂时仍可能显示中文。
- 全局弹层主题：全站 Dropdown、Menu、Select、Cascader、TreeSelect 等弹层在浅色主题下应使用白色背景、轻灰悬停和选中态，在深色主题下应使用深色背景与低对比度浅色交互态，不应再出现默认黑灰色块、文字对比不足或单个页面配色不一致。
- 画布节点缩放稳定性：选中任意节点并反复拖动四角缩放时，节点工具条应在缩放期间隐藏、松开后恢复，页面不应再出现 `Maximum update depth exceeded`。
- 画布文本设置：文本节点和生成配置节点切换到文本模式后应显示推理强度设置，可选择自动、低、中、高、极高；选择自动时后端 OpenAI 请求不应携带 `reasoning`，选择其他档位时应携带所选强度，刷新画布后节点设置应保留。
- 生图工作台参考图：将一张或多张图片拖入参考图区域后应直接上传并显示缩略图；拖入非图片文件应忽略，拖动过程中区域应显示高亮提示，放下文件不应导致浏览器打开或替换当前页面。
- 工作台历史图片清理：生图或视频工作台生成内容后，在「我的素材」删除图片、删除画布图片节点、清空画布或删除画布，再次打开对应生成记录时，历史缩略图、结果图片和参考图仍应正常显示；删除生成记录时，其专属本地文件仍应正常清理。
- 视频创作台参考资产：将图片、MP4/MOV 视频或 MP3/WAV 音频拖入任一参考资产区域后，应按文件类型自动上传到对应列表；当前拖入区域应显示高亮提示，原有数量、大小、时长和格式限制应继续生效。
- 画布组装提示词：输入或连接超长提示词后，浮层正文高度不应继续撑大，内容应可在正文区域内滚动查看和编辑，标题及关闭按钮保持可见。
- 画布节点提示词：图片等节点下方的提示词超过输入区域高度后，鼠标悬停在输入区域内滚动应查看提示词内容，不应缩放画布。
- 画布节点提示词回显：单图或多图生成完成后，切换选择生成结果的根节点及任一子节点，下方输入区域都应继续显示生成时的提示词；切换到其他节点再选回来后也不应清空。
- 画布生成配置：连接文本节点后连续点击生成（包含失败重试），组装提示词不应重复追加上游文本；在生图、文本、视频、音频之间切换时，实际请求应始终使用当前面板展示的对应类型模型。
- 画布多图生成：开始生成 N 张图片后应立即创建一个包含 N 个可展开槽位的图片节点，并且来源到结果只保留一条连线；生成期间空槽位应独立显示生成中或失败，任何已有图片内容的槽位都必须始终显示图片，任意图片率先成功后应立即成为主图并展示，不等待其他请求完成；收起状态应最多显示三层紧密错开的背板，避免占用过多画布空间，右上角应显示醒目的「N 张」数量提示；点击数量后，浮动工具条应暂时隐藏，各图片槽位应从当前节点向右上方整齐展开；已成功图片的「设为主图」应常驻显示，并在亮色、深色主题及不同图片背景上保持清晰；点击画布空白处应自动收起并恢复工具条。
- 画布多图主图切换：点击「设为主图」后，节点中心和当前最长边应保持不变，仅按新图片比例调整另一条边；自由变形节点应完全保持现有宽高，画布视口及左下角缩放值不应变化。
- 画布多图失败槽位：包括当前主槽位在内的每个失败槽位都应显示「重试」和「删除」；重试只更新当前槽位，已有成功主图时不得抢占主图；删除只移除当前失败槽位并同步更新图片数量。
- 画布多图尺寸调整：子图展开时开始拖动尺寸控制点，应先收起图片组一次，再正常调整根节点尺寸，不应触发 React 循环更新或应用错误页。
- 画布左侧元素列表：点击元素整行应平滑定位并选中对应节点，自动缩放不得超过 100%；有内容的图片元素应显示预览按钮，点击后打开大图弹窗且不触发画布定位。
- 画布两侧布局：Agent 面板位于左侧并从右边缘拖拽调整宽度，画布/资产/提示词资源栏位于右侧并从左边缘调整宽度；创作设定只从画布业务节点编辑，不再出现独立「设定」Tab。顶部开关、两侧进出动画和居中工具栏的位置应与各自方向一致；画布顶栏不再显示 Agent 连接状态、文档、版本号和 GitHub 入口。
- 火山方舟适配器：管理员选择「火山方舟」后，文本走后端 OpenAI-compatible，Seedream 图片和 Seedance 视频走固定适配器；能力选择由后台模型定义决定，不执行客户端脚本，参考视频继续校验大小、像素、宽高、比例和时长限制。
- 图片编辑弹窗：遮罩、切图和裁剪连续滚轮缩放时，图片与遮罩应保持同步且不再闪烁、短暂消失或跳动；遮罩画笔圆心应始终固定在鼠标位置，仅直径随缩放变化，缩放后仍可准确涂抹、拖动切分线和调整裁剪框。
- 提示词中心布局：页面标题及提示词总数应居中；连续输入搜索文字时应在停止输入约 300ms 后再查询；桌面端分类与标签应在左侧独立滚动，右侧搜索框下直接展示提示词卡片；标签数量较多时不能继续向下挤压提示词，窄屏下应恢复上下排列且内容不溢出；不再显示「我的提示词」Tab，收藏提示词应直接加入我的资产。
- 提示词详情弹窗：封面和参考图应固定显示在上方，复制及加入资产操作栏固定在底部，只有中间的标签、描述及提示词内容区域可以滚动；弹窗宽高应受视口限制且不超出屏幕。
- 提示词来源：6 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、53、76、126、129；提示词仍按 6 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。
- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。
- 画布提示词库：不应再显示「我的提示词」分组；不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。
