# Quick Start

This development milestone requires both `server/` and `web/`. Existing Docker, Render, and Vercel paths are not maintained until the production backend package is completed.

## Run locally

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
./dev.sh
```

Open `http://localhost:3000`.

To run without the machine-specific ComfyUI helper, start both packages in separate terminals:

```bash
(cd server && bun install && AUTH_MODE=dev DATA_DIR=../data bun run dev)
(cd web && bun install && bun run dev)
```

## First-time setup

- Development users are administrators by default. Open AI Services to configure shared providers, encrypted credentials, and model capabilities.
- Open `/prompts` to fetch prompt repositories directly from the browser and cache them in IndexedDB.
- Administrators manage public providers and ComfyUI nodes under AI Services, and WebDAV snapshots under Services and backups.

Canvas projects, assets, media, records, settings, and every AI generation task are backend-owned. The browser contacts only the same-origin application API and never receives provider credentials or internal ComfyUI addresses.
