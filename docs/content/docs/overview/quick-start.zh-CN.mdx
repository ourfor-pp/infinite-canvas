# 快速开始

当前开发里程碑需要同时启动 `server/` 和 `web/`。生产后端包完成前，原有 Docker、Render 和 Vercel 链路暂不维护。

## 本地启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
./dev.sh
```

启动后访问：

```text
http://localhost:3000
```

如果不使用当前机器专用的 ComfyUI 启动辅助，可在两个终端分别启动：

```bash
(cd server && bun install && AUTH_MODE=dev DATA_DIR=../data bun run dev)
(cd web && bun install && bun run dev)
```

## 首次使用建议

- 开发模式用户默认是管理员，先打开右上角「AI 服务」，配置共享渠道、加密凭据和模型能力。
- 如果需要提示词仓库内容，打开 `/prompts` 会由浏览器前端直连拉取并缓存到 IndexedDB。
- 管理员在「AI 服务」中配置共享公网渠道与 ComfyUI 节点，在「服务与备份」中管理 WebDAV 完整快照。

## 说明

- 画布、素材、媒体、生成记录和设置由后端保存。
- 文本、图片、视频和音频模型全部由后端调用；浏览器只访问同源 `/api`，不接收供应商地址或密钥。
