# H3-World 可控生成候选

H3-World 值得用于人物移动和镜头运动的后续实验，目前不替换导演台 Ref2VA 默认链路，也不计入已实现的加速收益。

作者将键盘状态转换为逐 latent 的语言指令，并用定向注意力把指令约束到对应时间区间；训练使用 8,000 条游戏视频和约 6,560 万 LoRA 参数。发布权重声明 Apache-2.0，基础 H3 仍受自身许可证约束。以上是作者披露，尚无本地复现实验。[模型卡](https://huggingface.co/DANNY621/H3-World)

运行需要作者指定的 DiffSynth 提交、注意力补丁和原始 FL2VA 权重；不能只把 LoRA 放进现有 ComfyUI 就认为具备同等控制。作者示例使用 50 步、124 帧、CFG 1.0，输入按需中心裁到 832×480，提供静止、前后移动、横移、俯仰和左右摇镜等预设。仓库提供同名 ModelScope 来源，若开展实验应先固定仓库与权重 revision，再建隔离环境。[作者代码与示例](https://github.com/Danzer1xxxxChan/H3-World)

当前判断：它可能帮助解决机位和运动指令失控，但游戏数据上的动作控制不能直接证明写实短剧的表演、对白口型和角色一致性。50 步示例也不支持“更快”的结论。先完成现有 Ref2VA 提示与参考图一致性检查；若基础链路仍无法保持机位，再用相同首帧分别测试静止、单向摇镜和人物单向移动，记录运动服从、画质损失、显存与耗时。未经该对照，不与 PDD 加速方案叠加推广。
