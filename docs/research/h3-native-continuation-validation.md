# H3 原生音视频续接实验

基础20步已完成一次481帧、约20.04秒的生成阶段连续续接；PDD八步同条件实验亦已完成。当前只证明本机机制可运行与初步边界观察，尚不能称为无破绽续接或成片质量通过。正式导演台默认未改。

## 机制与输入

隔离8190加载[原生续接节点](https://github.com/ttulttul/ComfyUI-Minimax-H3-Continuation/tree/e1768d5fdfc6f9519d2090dcf78458c2d9625f80)，固定该revision。三个节点分别创建续接窗口、把上一段音视频latent尾部注入原生时间引导、裁去新窗口的重叠后追加新增latent。累计音视频统一解码，没有通过溶解或后期切换掩盖边界。

使用同一泳池参考、种子271828、960×544、24fps。初始124帧，三次各追加119帧；每次窗口141帧、其中22帧为隐藏上下文。边界在5.1667、10.125、15.0833秒。音频追加token数为198、198、199，按累计时间位置对齐。官方Ref2VA六段式提示保持固定，续接窗口不再要求说话。

## 基础20步证据

- 完整视频可下载并解码出481帧，视频SHA256记录在实验结果。
- ComfyUI执行事件耗时442.141秒，日志总耗时442.99秒；监控进程中途退出后查询同一任务并恢复下载，没有重提生成。该口径不包含传输，不直接与前批监控墙钟耗时混算。
- 因监控中断，完整峰值显存未知，不以初始值或部分采样冒充全程峰值。
- Qwen对完整视频识别为原台词一次，发声约1.92–3.36秒；不能据此宣布所有续接声音均无瑕疵。
- 检查1fps总览及三处边界前后三帧：未见明显硬切或人物位置复位。泳者持续前进，镜头跟随并逐渐露出池沿，原始固定机位要求未满足。
- 边界缩小图相邻帧平均像素差约5.78、5.57、6.14；全片中位5.02、P95为6.19。仅作定位辅助，不能证明运动、物理或声音自然。

完整播放、游泳肢体与水花物理、音频接缝、跨段音色和更多场景仍待验证。此实验不含双人对白、角色近景或768p，不能替代《留灯》样章验收。

## 复跑

固定ComfyUI与模型环境同[三种子测试](minimax-h3-multiseed-validation.md)，额外在隔离服务安装上述固定节点。原参考图来源同泳池fixture；图中使用已上传的 `ref2va_test_5_3.jpg`。

```bash
python3 media-executor/scripts/benchmark-h3.py \
  media-executor/examples/h3-evaluation/continuation-native/base20-481frames.json \
  --output .tmp/h3-evaluation/continuation-native/base-rerun
```

PDD对照替换为同目录 `pdd8-481frames.json`，使用另一输出目录；必须串行运行。完整结果、提示与工作流在 `media-executor/examples/h3-evaluation/continuation-native/`；原视频、接缝视频、逐帧图和原日志在 `.tmp/h3-evaluation/continuation-native/`。当前仍为实验材料。

## PDD八步对照结果

同口径ComfyUI执行221.856秒，基础442.141秒，约1.993倍加速；基准脚本墙钟222.903秒。PDD整卡采样峰值32066 MiB，基础完整峰值缺失，不能据此比较节省显存。两套ASR均为原句一次，Qwen发声1.92–3.36秒，独立VAD仅在开头约1.63–3.70秒检出语音。三处边界逐帧未见明显硬切或位置复位，镜头跟随仍在；完整播放、物理运动与听音仍待验收。

接缝平均像素差约5.18、5.31、5.69，全片P95约5.82；这不构成质量评分。该单场景单种子只支持继续人物镜头对照，不提升正式默认，也不能计算每秒合格成片成本。
