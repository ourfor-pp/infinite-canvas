# H3 原生声音续接最小实测

本文只覆盖原有双流续接。后续已完成社区“零画面、39 帧音频上下文”的独立实测，见 [社区音频续接对照](h3-community-audio-continuity.md)，不能用本文结果代替社区方案结论。

## 结论

现有基础模型双流续接可以完成这组短对白，状态文件确实保留了前段视频和音频潜变量；提示词要求切近景时，本次新增片段从第一帧起已经是近景。不能据此认定跨镜头必须先增加音频独立续接功能，也不能认定双流续接能稳定满足所有切镜。

声音质量尚未通过验收。切近景后的对白窗口 RMS 比上一段高约 11.5 dB，明显偏离相同轻声表达的设计；接缝本身的低音量区域变化较小，不能以此代替整段声音一致性检查。独立生成对照的接缝音量变化也很小，本次没有证明原生续接在主观听感上优于独立生成。

## 测试条件

- 通过现有执行器 8290 的协议 2 API 排队，未重启、安装或修改运行时，未取消其他任务。
- `minimax-h3-ref2va-local`，`recipe=base`，`qualityPreset=preview`，864×480、24 FPS、原生 32 kHz 音频。
- 独立灯旁老人场景，一张已有参考图，无音色参考、无配乐。此项测试关注续接机制，不验收作品中的角色音色资产。
- 请求每段 4.25 秒；独立生成按模型网格输出 107 帧（4.458 秒），续接新增 102 帧（4.25 秒）。续接隐藏上下文为 22 帧。
- A：首段 → 双流续接 → 提示切近景的双流续接，总时长约 12.958 秒。B：同一首段 → 独立生成对照，总时长约 8.917 秒。
- 不加淡化、响度归一化、降噪或后配音。拼接时按视频时长裁掉音频编码尾部填充，再直接拼接；原始分段和累计输出均保留。

## 接缝与状态检查

| 接缝 | 时间 | 前后各 250 ms 的 RMS 变化 |
| --- | --- | --- |
| A：首段 → 同镜头续接 | 4.458 秒 | +1.64 dB |
| A：同镜头续接 → 切近景 | 8.708 秒 | -0.26 dB |
| B：首段 → 独立生成 | 4.458 秒 | +0.62 dB |

接缝窗口约为 -55 至 -54 dBFS，较安静；这些数值不足以证明雨声的声场、频谱或听感连续。对白区域另行测量：02 的 1.68–2.80 秒为 -21.94 dBFS，04 的 1.68–2.64 秒为 -10.45 dBFS。不同句子本身也影响 RMS，11.5 dB 差值是需试听的响度异常线索，不等同于 LUFS 或人声分轨测量。

01 → 02 的状态张量前缀逐元素相等：视频从 `[1,24,32,30,54]` 增长到 `[1,24,62,30,54]`，音频从 `[1,32,2,178]` 增长到 `[1,32,2,348]`。累计输出与单独分段在接缝前 250 ms 的 RMS 仅差约 0.02 dB；独立 AAC 编码存在差异，不能把波形差异全部归因于 VAE。
