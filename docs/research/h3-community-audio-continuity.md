# H3 社区音频独立续接实测

## 结论

社区的“画面独立、声音延续”核心路径已在隔离环境实际生成成功。本组切到近景，后续对白正确，未转写出上一句的重复内容；对白窗口 RMS 比首段高约 0.67 dB，比独立生成和现有双流续接更接近首段。

但本组接缝前后各 250 ms 的背景区域 RMS 下降约 6.10 dB，不能认定声音无缝，也不能把单场景、单种子的结果推广为长片质量保证。保留原声供试听，不设置 `qualityAccepted` 或 `audioAccepted`。

## 测试了什么

源码：[ethanfel/ComfyUI-MiniMaxH3-Context-Loop](https://github.com/ethanfel/ComfyUI-MiniMaxH3-Context-Loop/tree/9860a063784c8c23b58e00107f2180e0df3c43d9)，固定提交 `9860a063784c8c23b58e00107f2180e0df3c43d9`，版本 0.6.9。ComfyUI 核心与当前部署一致，来自 `40c4fcdf513a4523e39d54a9d391908af8df8171`。

实际调用该提交 `nodes.py` 中的 `MiniMaxH3MotionContext.apply`，采用其已有的零视觉上下文路径。实验适配节点只暴露参数并记录条件，没有重写采样算法；没有测试社区完整的 Plan、Loop、Review Gate 界面流程，也没有部署到正式执行器。

关键参数：

```text
context_length = 0
audio_context_length = 39
audio_mode = timeline
context_latent = 同一首段实际生成的双流状态
```

采样前实际条件记录为：

```json
{
  "videoContextFrames": 0,
  "audioContextFrames": 39,
  "trimFrames": 0,
  "guides": [{
    "resolved_frame_index": -39.2,
    "audio_latent": [1, 32, 2, 65],
    "h3_chain_context_audio": true
  }]
}
```

没有上一段的视频 Guide，音频来自上一段采样状态的末尾 65 个音频步长，即 1.625 秒。负位置来自社区时间线对齐及源音频网格取整，不是普通音色参考，更不是后期贴音轨。新片段仍使用原角色图片作为独立身份参考。

注意：社区 `Hard AV` 表示保护画面和声音前缀，不等于硬切画面。默认 `Cut` 会把音频上下文也设为 0；本实验明确通过高级参数指定零画面、39 帧声音上下文，不能只切换界面预设就宣称启用了此路径。

## 对照设计

- 一个灯旁老人场景，共同首段种子 91611；三个后续均为同一句对白、同一近景提示、种子 91612。
- 基础 Ref2VA，20 步，864×480、24 FPS。提示要求持续雨声、低强度持续配乐与中文对白；雨声及音乐的实际听感尚未验收，不能把提示要求视为输出已符合。
- 首段、独立后续、社区后续各 107 帧（4.458 秒）；现有双流续接新增 102 帧（4.25 秒），按各自原生网格输出，时长差保留在报告中。
- 首段：“外面还在下雨。”；三个后续均为：“等雨停了再走。”
- 未添加淡化、响度归一化、降噪、后配音或额外音乐。视频拼接只裁掉编码尾部填充，再直接连接。
- 社区原生 Guide 和委托适配的两项现有单元测试通过；真正的能力证据来自后续真实采样与条件记录。

| 后续方式 | 对白窗口 RMS | 相对首段对白变化 | 接缝背景窗口变化 |
| --- | --- | --- | --- |
| 独立生成 | -12.08 dBFS | +9.28 dB | +5.38 dB |
| 社区音频独立续接 | -20.69 dBFS | +0.67 dB | -6.10 dB |
| 现有双流续接 | -16.96 dBFS | +4.41 dB | +0.18 dB |

首段对白 RMS 为 -21.36 dBFS。对白窗口由本地 Qwen3-ASR-0.6B 与 ForcedAligner 辅助定位；RMS 来自混合音轨，不是人声分轨或 LUFS。背景窗口固定取切点前后各 250 ms，这些低能量窗口只反映局部变化，不能判定音乐旋律、空间、频谱与主观连续性。

四段转写内容均与目标一致（忽略标点），没有数字削波。已查看联系表及各后续首 12 帧，三种方式本次均进入近景；社区与独立生成额外出现了字幕，现有双流续接的灯移到了画面另一侧。这些画面问题也意味着样片不是成片验收通过。

## 隔离与恢复

源码和运行副本位于 `.tmp/h3-community-audio/`，临时 ComfyUI 只监听回环 8192，权重和依赖复用现有只读文件。正式运行时、配置及导演作品未修改。

单卡测试前临时设置正式执行器维护标记，等待已有任务与代理提交排空；使用项目现有 NVML `Scheduler` 串行运行隔离推理。结束后停止自建进程、释放显存并移除本次维护标记，认证检查确认正式执行器 `ok=true`、`maintenance=false`、`h3Ready=true`。未取消用户任务，未重启正式服务。

首轮推理在保存时因隔离输出根目录缺失失败，已补齐目录并按相同参数重跑；失败 history 和日志另存，没有计入有效样本。四个有效样片耗时约 76、75、75、105 秒，包含节点加载、采样、解码、保存与轮询，不是纯采样耗时。
