# 导演 v2 实施与验收

## 已实现

镜头设计以 `shot.md` 表达完整创作意图；制作任务以 `task.md` 记录多对多镜头引用、显式媒体输入及最终提示；独立 `videoClips` 决定采用素材与裁切。模型窗口只约束任务预检。生成成功且媒体处理完成后替换当前输出，运行、失败和取消保留旧结果；不会自动追加时间线。

声音支持任务原声与导入媒体，使用独立开始位置、入点、时长、音量及已有淡入淡出字段。原声解关联后不会重复混入关联声音。预览与导出共用播放计划，累计续接映射到源文件时间；失效裁切返回 409。合成提交复制输入媒体并保存剪辑快照，重试沿用这份快照。

## 自动验证

- 格式、长镜头、任意故事板布局、任务关联与来源校验。
- v1 转换的媒体字节/ID/提示保留、数据库备份、失败目录回退、备份冲突拒绝和重复执行。
- 重复裁切、累计素材、独立声音、短结果越界、失败保留、空时间线及基于选片的节拍覆盖。
- 真实 FFmpeg 集成验证裁切/声音与媒体快照，提交后替换源文件不影响已提交导出。
- 原有接口、同步、H3、Agent 媒体工具与前端同步回归，前后端类型检查和构建。

节拍覆盖是关联层检查，不能证明裁切后的画面或声音真的表达了该节拍；必须审看实际成片。
