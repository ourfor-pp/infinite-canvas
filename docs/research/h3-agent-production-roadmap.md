# 导演 Agent 长视频落地路线

目标从模型实验转向真实导演工程：默认加速、可复用创作方法、可修改过程与完整视听验收共同完成。保留既有 42 秒样片和实验结果，但不能把手工构造工程作为 Agent 创作验收。

## 默认加速接入

当前 PDD 图仅存在于实验构图器。生产 Ref2VA 仍为基础 20 步；续接状态运行时身份只覆盖基础模型和实现，未区分 PDD 权重。必须先建立可用性与配方身份，再接默认选择，避免基础与加速来源被当成同一状态。

已增加执行器 `pddRef8` 可用性字段，依据真实节点权重选项，应用目录透传。回归覆盖节点缺失、空权重及目标权重存在，服务端类型检查通过。此字段仅代表可选择，不能代替权重哈希或推理证明。当前隔离 8190 连接拒绝，恢复环境前先重新核对宿主部署，不沿用旧进程假设。

后续依次完成：配方与权重身份、默认/基础重做选择、普通与续接状态校验、Agent 和界面入口、真实应用生成及部署。Ref2VA 与 FL2VA 分开；参考音频、参考视频及原生续接分别保留验收状态。

## 配方身份接入进展

运行时新增 `recipe=pdd-ref8` 身份查询，独立于基础配方缓存。模型身份附加 PDD 权重、实现及其 JSON/safetensors 辅助数据、八步 Euler 和双增量强度等固定参数的摘要；文件变化后拒绝继续使用已加载环境。保存/读取状态按对应配方校验，应用目录分别保存基础与 PDD 身份，未就绪时不混用。节点来源及模型目录已对照[固定 PDD 实现](https://raw.githubusercontent.com/Jalen-Brunson/ComfyUI-MiniMax-H3-PDD-Acc/311a65dd53832d8a5f8177a9d5fb923c09e35a90/nodes.py)核对。

13 项状态/指纹测试通过，包含基础/PDD 隔离、相同内容不同路径一致、权重与实现变化后拒绝旧状态；执行器能力/身份回归通过。尚未在真实 ComfyUI 上运行新查询，也尚未接生产生成图的配方绑定与默认选择。本轮没有重新标记旧状态；运行时代码变化会使旧实现指纹失配，恢复验证需使用对应旧运行时或重新生成状态。

## 生产生成图接入

生产构图器支持显式 `h3Recipe=pdd-ref8` 与 `base`，PDD 使用官方八步增量节点输出 sigma 和 Euler，参考图尺寸按已测配方采用 match；实验构图器复用同一接线。基础配方保留原二十步调度。PDD 不能用于 FL2VA，未知配方被拒绝；保存状态的模型身份必须与所选配方一致。

构图回归覆盖图片/音频/视频引用、时间锚点、基础重做、续接累计双流及身份错配拒绝，两份工作流测试文件通过。此处只证明图结构；导演默认选择、API/Agent/界面重做入口以及新版本真实生成仍待完成。

## 导演默认选择与 Agent 参数

默认策略已接入后端提交与预检查的共用选择函数：普通 Ref2VA 图片参考在执行器节点、权重选项和 PDD 身份均就绪时默认八步；独立参考音频仍默认基础配方，不能把此前图片输入的对白生成速度推广到音频参考。续接继承前段状态对应配方，显式跨配方续接拒绝并提示从连续镜头首段重做。首尾帧保持原路线。HTTP 生成输入和 Agent 视频工具新增可选 `recipe=base|pdd-ref8`，省略时使用默认规则；实际配方写入生成参数和提示快照。

工作流、实验图和导演渲染三个测试文件通过，服务端类型检查通过；目前还缺 HTTP/Agent 新参数端到端回归、界面配方显示及基础重做入口、新运行时真实推理与部署。不能把代码默认选择称为正式服务已切换。

## 界面与请求验收

视频模式显示将使用的“加速生成／基础生成／首尾帧生成”；加速独立段提供“基础版生成”按钮，以 final 质量显式提交 recipe=base。续接段不提供跨配方按钮。浏览器回归核实默认请求省略 recipe、基础版请求明确携带 base，以及续接按钮隐藏；前端类型检查和构建通过。首轮夹具缺当前导演同步接口，页面未进入分镜；补齐新测试的同步响应后通过，不作为产品修复。当前仅浏览器模拟 API 验证，仍需真实 HTTP/Agent 与运行时验收。

## 真实 HTTP 与 SQLite 配方验收

隔离应用测试通过真实 HTTP 创建导演工程、保存剧本与场次拆解、创建视频段并登记故事板，再调用预检查及生成接口。已验证默认 PDD 八步、显式基础二十步、加速不可用时默认基础，以及显式请求不可用加速返回 409 且不创建任务。返回配方参数与 SQLite 生成记录完全一致，状态指纹分别对应 PDD 与基础身份。

测试以模拟执行器提供目录，所有生成请求随后取消，不执行 GPU 推理；它证明真实应用路由、校验和持久化，不证明渲染结果或速度。初期夹具遗漏剧本/场次映射，被真实校验拒绝，补齐后通过。测试：`app.test.ts` 的“导演 HTTP 默认 PDD 和基础重做保存真实配方参数”。Agent 工具端到端、续接实际生成及新运行时部署仍待验证。
