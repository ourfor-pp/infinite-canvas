## 固定输入对照

用例见 `media-executor/examples/audio-acceptance/cases.json`，本机请求、输出、诊断和评估位于 `.tmp/v0152-acceptance/`。

- ASR：官方 Google FLEURS test 集，revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd`，CC-BY-4.0。推理前固定每种语言前八条，共 24 条，采用其发布的朗读转写标注，并非本次重新听写。两个模型共 48 次全部完成。
- TTS：旁白、情绪、多音字及数字、长段落四类，每类两个固定 seed，Qwen/Vox 共 16 次全部完成。另以 Qwen3-ASR 1.7B 回读全部输出。
- 音乐：12 份同输入简报分别交给 Music3、ACE，共 24 项。ACE 四项首次因冷启动健康等待不足失败，修复后四项重试全部成功，原始失败记录保留。不得将重试后的结果描述为零失败运行。

CER 使用 NFKC、小写、移除标点和空白，不进行数字文本转换；繁简统一结果另列。每语言仅八条，不能据此作通用模型排名。

| 语言 | 1.7B CER | 0.6B CER | 繁简统一后 1.7B / 0.6B |
| --- | ---: | ---: | ---: |
| 普通话 | 10.96% | 10.63% | 10.96% / 10.63% |
| 粤语 | 10.45% | 6.34% | 2.24% / 3.73% |
| 英语 | 4.69% | 3.13% | 4.69% / 3.13% |

TTS 回读：两模型旁白均为 0 CER，长段落均为 2.70%；Qwen 情绪两次为 3.33% / 36.67%，Vox 均为 0；发音数字类 Qwen 为 5.17%，Vox 为 6.90%。数字写法（如 A307 与 A三零七）会影响该指标；情绪样本异常需听审，不能直接归因于 TTS。回读一致不证明音色、口型或自然度达标。

## 调度与恢复实测

- ASR → Qwen → Vox 连续三轮，后两轮模型加载次数保持不变，加载耗时和驱逐次数为零，验证小模型驻留复用。
- 大小模型交替时先清缓存、卸载；仍不足时仅停止空闲受管进程，解决 ASR 卸载后残留显存导致排队的问题。
- Music3 执行期间重启执行器，同一 upstream prompt ID 恢复并完成，没有重复提交。
- Vox 参考克隆及 ZipEnhancer 去噪、ASR 参考文本强制对齐均完成真实推理。
- H3 原有 243 帧状态延续到 345 帧；新旧视频 latent `[1,24,72,30,54]` → `[1,24,102,30,54]`，音频 `[1,32,2,405]` → `[1,32,2,575]`，原始前缀逐元素完全一致。保留 PDD 原指纹，没有重标旧状态。冷启动会等待对应运行时指纹就绪。
- 52 个隔离音频输出全部可解码且非静音；此检查不代表听感质量通过。
