# MiniMax H3 多场景复核

> 版本范围：本文 LightX2V 结果仅对应 Ref2V v0.1 四步权重。后续检索发现作者已发布 Ref2V v1.0 八步版，尚未实测；社区相近异常与适用修复见[调查记录](./minimax-h3-community-anomalies.md)。

## 评测范围

在首批六项对照之后，追加四个任务 × 三套 Ref2VA 配方。任务为先说话再移剑、摩托车人物对白、泳池画外音、无对白水面。每个任务使用基础模型 20 步、LightX2V 4 步和 PDD 8 步，固定 seed 314159、960×544、124 帧、24 fps。每项只运行一次，不构成多种子统计结论。

四份提示均按 [MiniMax 官方 Skill 固定版本](https://github.com/MiniMax-AI/MiniMax-H3/tree/d21241f0a4b3acbb34c97dae47fa417b7065e438/skills/h3-prompt-writing) 编写：Ref2VA 六段、Shot 前风格句、376–395 词详细描述、稳定参考标签和原文对白。输入与来源哈希保存在 [second-batch](../../media-executor/examples/h3-evaluation/second-batch/)。前一轮原任务是先移剑再说话，此轮改为先说话再移剑；这是任务顺序干预，不能视为只改时间数字的严格单变量实验。

沿用同一独立运行时、剪枝量化基座和 GPU 环境。各项依次卸载模型、禁用节点缓存后生成，端到端时间包含加载、编码、采样和保存，约有 2 秒轮询粒度。所有图都含一个参考图片，尚未覆盖产品实际使用的多参考图与整张故事板输入。

## 评测标准

- 内容：ASR 转写与目标台词比较时只去除标点和空白，保留原始识别结果；无对白任务期望空转写。
- 时间：在查看本轮 ASR 结果前规定 ±0.25 秒容差，分别输出“首尾边界匹配”和“位于窗口内且按时说完”；后者允许提前结束。
- 视觉：人工查看每段第 0、24、48、72、96、120 帧，即 0–5 秒每秒一帧；明确记录动作、机位偏差和无法从抽帧判定的事项。抽帧不是完整运动、口型或听音验收。
- ASR：所有 GPU 计时结束后，用已有离线 Qwen3-ASR-0.6B 与 ForcedAligner-0.6B 在 CPU 运行。强制对齐不是精确音素边界，识别非语言声音也可能产生误报。

## VDN 路径核对

进一步检查固定社区节点的 `vdn_h3/apply.py`：`merge` 分支检测到剪枝基座后主动移除 AdaLN patches；`bypass` 可以借助 Turbo 节点中的 silu 时间嵌入表重新注入，但依赖时间网格和对应注入逻辑。[节点维护者的固定版本说明](https://github.com/Saganaki22/ComfyUI-VDN-H3/tree/7271c648d7c2ff61ae1a7342dd9761e4545a34c3) 记录了 bypass 在 8 步 DMD 上的数值精度和画面退化问题。因此，本轮没有把“切为 bypass”当成解决方案，也没有再跑已知缺失增量的 VDN 对比。

可复核的完整路径是使用保留原始 AdaLN 的基座执行 merge，并核对所有适配器加载情况；另一条研究路径是主体权重 merge、AdaLN 单独注入，再做数值与成片验证。后者尚无本项目验证结果，不能直接采用。当前机器只有 pruned H3 基座，本轮不把 VDN 宣称为已完整修复。

另核对原生节点：视频 FPS 为 24，音频 latent FPS 为 40，Audio VAE 输出为 32000 Hz。124 帧对应音频约 5.175 秒，与成片约 5.167 秒仅差毫秒级，不能解释首轮约一秒的对白迟到。

## 新发现与交叉复核

1. **LightX2V 出现额外重复画外音。** 泳池任务要求一句“慢慢来，保持呼吸。”；Qwen 与独立 SenseVoice 均识别到重复两遍。另截取 3 秒之后的尾段，LightX2V 仍识别到“保持呼吸。”且 FSMN-VAD 检出约 1.22 秒语音，基础/PDD 尾段均未检出语音。这组证据支持真实重复，不能仅按速度把 LightX2V 提升为含对白的默认方案。仍保留人工听音验收。
2. **无对白场景不能只靠 ASR。** 水面三项的 Qwen 输出“嗯”，SenseVoice 分别猜测“我想”“我想”和标点，且部分强制对齐塌缩为零时长。FSMN-VAD 对三项均未检出语音，更符合非语言水声被误识别的情况；没有据此判定模型额外说话，也没有仅靠 VAD 宣称声音合格。
3. **动作顺序可以改善，硬时间点仍不可靠。** 先说话再移剑的三项都在抽帧中执行了新的先后关系，但 4 秒仍能看到剑，5 秒才在画外，未达到提示要求的 3.75 秒。台词提前了，但相对新的目标发声窗口仍迟到。
4. **固定机位需要独立检查。** 泳池基础样片中，立杆从右侧进入并向左移动，而泳者保持在画面中部，提示要求的固定机位没有保持。LightX2V/PDD 缺少同样清晰的刚性锚点，现有抽帧不足以判定机位严格通过。人物与水面样片未见明显身份/整体布局崩坏，但细部肢体、运镜、声音与口型未完成全片人工验收。

## 实际迭代结论

- LightX2V 保留为快速画面预览候选；含对白、旁白的默认路由暂不提升，本轮已有可复核的重复台词案例。
- 基础模型与 PDD 在三种有对白任务中，两套 ASR 均识别到正确的一遍台词；PDD 可继续作为对白加速候选，但时间控制及听音仍需验收。
- 提示中的时间是待验证的意图。不要自动平移或改写用户台词来掩盖偏差；应保留计划与实际发声区间，供重新规划或显式重生成。
- 画面、机位、台词、时间、声音分别记录。无对白结果先结合语音活动检测，再核对 ASR；证据冲突交给听音复核。
- VDN 先解决完整 AdaLN 适配再比较。本轮所有方案仍是单图、单种子、约 5 秒，尚不代表多角色音色参考、多图/整张故事板输入、长视频或正式成片通过。
