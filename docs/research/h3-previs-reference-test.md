# H3 三维预演与角色参考对照

## 结论与边界

本次简单单角色镜头中，三维预演视频与角色身份图可以共同驱动 H3：生成结果将蓝色粗模替换为毛绒角色，并比仅身份图加文字更接近预演的构图、走位与动作时间。额外加入定妆图有助于确定道具结构、背景和光照。本例未使用分镜故事板，支持将故事板设为可选参考；不能据此认定复杂镜头也无需故事板或预演能被逐帧精确复刻。

## 固定条件

- 正式媒体执行器，H3 Ref2VA `pdd-ref8`，preview，864×480，24 fps，124 帧，实际约 5.167 秒，seed `91642`。
- Three.js 制作真实三维预演：蓝色兔子粗模从画面左侧走至中央，停下转向镜头、抬左臂，最后缓慢推镜；右侧固定灰色方块。不是由最终视频倒推生成的参考。
- 角色引用现有兔子身份板：米色毛发、橄榄绿背心、一只直耳一只垂耳。定妆图以粗模起始画面和身份板生成。
- 三组保持相同动作文字与种子，仅按输入增加引用声明。预演不带入参考音频。定妆图作为普通图片参考，没有设置首帧硬锚点。

耗时为单次任务记录，不包含预演制作、定妆图生成或人工审片，不构成速度基准。三组采样画面均未见身份板分屏或多出角色。

## 验证与限制

- 三个真实任务均成功，结果下载并校验；独立浏览器播放源预演及三份结果至结束，均无媒体错误。
- 已检查半秒间隔联系表和最终帧；尚未完成人工完整运动审片及声音听审。四路对照文件为静音版，单独输出保留原始媒体。
- 仅一个种子、一个简单角色、一个短镜头；多角色、遮挡、接触和复杂镜头调度未测，基础模型与 PDD 差异未测。
- 粗模实际抬手约至头侧，文字要求高于头部，二者有差异；定妆图也改变了粗模角色比例及朝向。因此不能将手高、姿态和尺寸的全部偏差归因于模型。
- 未接入产品预演界面，未修改导演作品或生成任务归属。
