# Deployment

1. Confirm an NVIDIA driver compatible with the runtime Torch build, at least 32 GB GPU memory for the complete catalog, and adequate model storage.
2. Copy or clone the repository to the GPU host. Keep `/data/sas/models` as the stable entrypoint, put only enabled models under the SSD/NVMe directory `~/.local/share/infinite-media-executor/models`, and symlink them into the entrypoint. Resolve every target with `readlink`, `findmnt`, and `lsblk`; require `ROTA=0`.
3. Create the gateway environment with `uv sync --extra test` and Qwen/MOSS adapter environments with `uv sync` in their runtime directories. Install the pinned ACE engine with `media-executor/scripts/install-ace-step.sh`; do not run an unpatched upstream cross-platform lock on the Linux host.
4. Run `media-executor/scripts/download-models.sh`. It downloads official ModelScope repositories directly to SSD at pinned commits, links the stable entrypoint, and records revision, target, and file-list hash in `MEDIA_MODEL_ROOT/manifest.json`.
5. On a developer host, run `media-executor/scripts/install-user-services.sh`, then configure the exact ComfyUI and ACE official engine units in the executor environment. If system units are listed, install the minimal sudoers template after replacing `MEDIA_USER` and validate it with `visudo -cf`. For system-wide production services, install templates from `media-executor/systemd/` and replace `/opt` and `/etc` paths explicitly.
6. Bind the gateway to the GPU host LAN address or `0.0.0.0:8290`; restrict it by firewall to the application-server address. The executor launches native workers on private Unix sockets; no per-model service registration is needed. Keep ComfyUI and ACE engine on loopback.
7. Configure the application server with the remote gateway URL and matching Bearer token through administrator services or environment fallback.
8. Verify gateway health, ComfyUI workflow probing, native runtime health, one sample per media class, server-side result persistence, acknowledgement cleanup, cancellation, and restart recovery. For ACE, submit through port 8290 and verify pressure-driven eviction and lazy recovery. Confirm concurrent Comfy proxy submission is rejected while another task owns the GPU. Native workers must support reattachment without duplicate inference and cancellation with actual process termination.
