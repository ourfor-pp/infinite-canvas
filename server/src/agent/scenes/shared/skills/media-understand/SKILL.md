# 媒体理解

- 图片：使用原生看图读取工作区图片路径。附件提供可读路径，画布图片通过 canvas_get_state 返回的 metadata.path 读取；先实际打开图片再描述，不能用文件名或文本描述替代可见证据。同组图片按顺序比较，细节不清时查看原图。
- 声音：使用当前注册的声音理解工具，按工具定义传入文件引用或工程相对路径。只报告可听证据，不能把语义理解当作精确转写或逐词时间。
- 视频：先取均匀覆盖全片的联系表，再针对明确接点或动作时间抽帧。按当前工具 schema 选择取样模式和输入，返回的图片路径用原生看图读取。
- 输出区分观察、推断与不确定项，并保留源路径及时间点。联系表不能证明所有中间帧正常，首尾图不能证明运动流畅。不要把音视频文件作为文本读取。
