# 导演台故事板规划

按剧情段落建立 sequence，每段规划 4–9 格，覆盖建立、推进、转折和收束。每格明确画面目的、动作、对白或旁白、景别、机位、运镜和时长，并绑定稳定资产 ID。

先创建或更新结构化故事板；只有阶段条件满足时才拆成独立镜头。不要把整张故事板当成不可拆分的大图。
