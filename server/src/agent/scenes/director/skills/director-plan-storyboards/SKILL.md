# 镜头规划

先读 [v2 文件格式](references/file-format.md)、[场景与制作规划](references/segment-planning.md) 和 [镜头语言](references/storyboard-language.md)。按需分页读取当前剧本、制作拆解、导演规则和视觉风格；不要一次读全工程。

先为完整场景设计观看顺序、人物调度、视线、画面、动作、对白、声音和衔接，再规划主画面、必要反应与补充覆盖。保留表演的铺垫、停顿、转折和后果，不为模型窗口截短文字镜头。素材未齐也能完成全部文字设计。

镜头条目写入 `storyboards/<场景>/shot-<ID>/shot.md`，所属场景保留 `sequence.md`。镜头记录来源场次与节拍、叙事目的、人物调度、摄影、动作、对白、声音、预计时长和开始/结束状态。预计时长表达创作意图，没有 4–15 秒限制。

## 条目与故事板

当前分镜页按 `shot.md` 列出条目，每项展示自己的整张故事板。先按完整动作、观看顺序和叙事转折组织条目，再在条目正文内写板内各画面的机位、动作、对白、声音及衔接；一次切镜或一个画格不自动等于一个列表项。若多个画面共同组成一张故事板，就合在一个条目中，完整保留其来源节拍和预计时长；不要机械地按整场合并，也不按生成时长上限拆条目。

一张输出故事板只归属一个条目，不得将同一图片和整板提示词复制、硬链接或软链接到多个镜头目录，冒充逐镜完成。需要独立条目的内容应各有对应的画面设计与故事板；已采用的其他故事板可以显式用作连续性输入，但不能当作本条目的输出。用户要求按最新技能重做重复板时，先核对各项内容，按上述语义合并、保留全部动作并更新受影响的来源与任务关联；有旧媒体或其他依赖的目录先按工程约定归档，不直接删掉有效成果。

## 画幅与排版

绘制前读取导演规则摄影章节的成片方向与宽高比，每个画格都继承这个画幅；方案未明确时先按 `director-design-style` 补齐决定。整板的行列布局与单格画幅分别描述：提示词必须写清单格宽高比、行列数、阅读顺序、每格内容和整板目标比例，工具支持尺寸或比例参数时同步设置。等大格的整板比例约为“列数 × 单格宽度 : 行数 × 单格高度”（分隔线另计），不能只写“横版故事板”。

延续已采用的网格与阅读方式，不因五个动作就改成五列竖条。例如横版 16:9 单格的 2×2 四格板整体也约为 16:9；五个必要画面可组织为两列三行并明确余格处理，或在同一条目下分页，不能强塞进一排或为了凑四格删掉必要动作。竖版项目同样保持每格 9:16，不强制所有项目四格或整板 16:9。板内格数、行列可按叙事需要调整，但不得改变既定单格画幅、挤压人物构图或打乱阅读顺序。

生成后按 [连续性核对](references/continuity-qc.md) 同时检查实际文件尺寸、整板布局和每格构图比例；不能把提示词写过比例当作结果已满足。模型把横格画成竖条、漏格或比例明显偏离时，标为未通过且不采用，不拉伸图片伪装修复；按现有生成授权与重试规则处理。

## 绘制前的素材准备

只做文字分镜时不要求先出素材图；用户要求“绘制故事板”“故事板都做完”时，素材检查与补齐属于本次绘制流程。读取当前各条目实际需要保持一致的角色、场景和关键道具，组合 `director-breakdown-assets`、对应角色/场景/道具设计 Skill 与 `director-generate-assets`，优先复用工程内已有可用主图，只补缺口。不要跳过正式素材设计，在第一张故事板中临时创造主要角色，再把该板当成全片唯一身份依据；统一风格板中的示例主体也不是正式角色。

生成前实际查看所选主图，在本条目 `prompt.md` Frontmatter 中声明采用路径与用途，正文图号、实际工具输入顺序保持一致。按当前工具参考预算选择对本条目有作用的输入，不强塞全库素材；普通背景细节无须独立建档。必要主图生成受阻时如实说明尚未完成的部分，不用无引用的整板代替素材准备，也不把文字分镜完成当成故事板全部完成。

一个镜头可由多个制作任务实现，一个任务也可覆盖多个镜头。素材可重复覆盖同一段戏，为后期提供不同视角；不要求生成总时长等于成片时长。需要安排生成时组合视频生成 Skill，在 `productions/` 另建任务，不把生成参数放进镜头设计。

视频制作的参考图片是可选输入：可使用单张画面或任意数量结构化关键时刻的多宫格说明，不要求每个镜头先生成图片，也不固定每张参考图的格数。整张参考图仍作为一个媒体文件操作。普通图片使用宿主原生生图能力，遵循工程落盘与索引约定。

视觉风格约束媒介、真实程度、色彩、材质、光线和摄影质感。剪辑节奏由剧本与表演需要决定，不从风格说明继承无依据的快切或蒙太奇。

修改前读取当前文件哈希；保存后运行 `director_validate`，并实际检查每项输出对应其正文、主图引用有效、不同条目没有重复整板；文件校验通过不代表这些创作检查已通过。已有任务受镜头变化影响时标记待检查；未经授权不重生成。计划时点只是意图，实际切点必须查看生成视频才能确定。
