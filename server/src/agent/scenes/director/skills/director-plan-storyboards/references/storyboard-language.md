# 故事板与视频段

生成单元是 4–15 秒视频段。一张故事板对应一次视频生成，内部画格表示同一段的关键时间点，允许最多 3 个明显 Shot。

- 4–6 秒：默认 `2×2`，4 格。
- 7–10 秒：默认 `3×2`，6 格。
- 11–15 秒：默认 `3×3`，9 格。
- 超过 15 秒：按动作或叙事转折拆段。

格数由内容密度校正：每个独立视觉节拍至少一格，每个明显 Shot 至少安排首尾状态；静态长镜头可以降档，复杂动作可以升档，但只能选择 4、6、9 格。一个视频段最多 3 次明显切镜，9 格仍不足时必须拆段，禁止用更密的小格掩盖过载剧情。

每格记录 Shot 编号、时间点、`shot-start | keyframe | shot-end`、画面、动作、机位、运镜和声音。固定宫格整板一次生成；禁止逐格生图、标题、编号、字幕、气泡、Logo 与画中画。

参考图优先级：主角色、其他出镜角色、场景、关键道具、当前风格。最多 6 张，未采用项必须向用户展示。缺主角色或场景时停止并匹配素材。
