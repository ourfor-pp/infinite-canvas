# 镜头与参考图片

镜头是连续观看意图，包含构图、轴线、人物调度、动作阶段和摄影运动。主画面、反应与补充覆盖服务于同一场景表演，可以拥有重叠的戏剧时间。

单图和多宫格都是可选参考。多宫格表示关键时刻或不同镜头的观看顺序，整张图片作为一个媒体文件查看；不拆成逐格生成目标，不把计划格间分界当成实际视频切点。

制作任务可以不使用故事板。采用参考图时在 `task.md` 的 `referenceImages` 中明确路径，并在 `video-prompt.md` 正文解释实际用途；程序不自动补写创作语义。

同一镜头内保持身份、空间、视线和运动方向，只有创作上明确切换视角时才要求切镜。长表演不能靠增加关键帧数量冒充完整叙事。
