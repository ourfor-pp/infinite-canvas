人物停步、观察门缝，经过充分迟疑后抬手敲门。不缩短停顿来适应生成窗口。

## 板内画面

1. 中景：人物走到门前停住，观察门缝。
2. 近景：目光由门缝移向门板，迟疑后抬手。
3. 手部细节：敲门后手停在半空，等待回应。

这些画面共同呈现一次“迟疑到决定”的变化，放在本条目的一张故事板中，不另建三项并重复保存整板。
