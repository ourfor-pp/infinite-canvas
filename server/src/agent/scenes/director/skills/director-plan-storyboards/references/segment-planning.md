# 从完整场景到制作任务

1. 读场景的开场状态、戏剧变化和结束状态，核对必须保留的动作、对白与反应。
2. 设计场景观看顺序、空间轴线、人物调度和摄影；先确定可承载整段表演的主镜头。
3. 补充有叙事作用的反应、插入与细节覆盖，不为凑镜头数机械切换机位。
4. 镜头按创作所需估计时长，长镜头可以跨多个制作任务，反应镜头可单独生成；允许不同视角素材覆盖相同戏剧时间。
5. 安排制作时查询实际模型能力，把同一镜头的连续动作分配给有依赖的任务，或把多个可切换镜头放入一个任务。限制只作用于任务。
6. 生成后检查实际表演与切点，按可用范围选片。不要直接用计划画格时间裁切。
7. 完整性以预期剪辑是否表达剧本必要内容为准，不要求各任务时长守恒。无法靠现有素材表达的内容列为明确缺口。
