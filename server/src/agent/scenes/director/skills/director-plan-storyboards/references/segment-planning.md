# 剧本到视频段

## 先守恒，再分段

先逐场列出全部节拍 ID、台词、旁白、动作、反应和计划时长，再拆成 4–15 秒视频段。拆分后逐项回查：每个来源节拍至少被一个视频段覆盖，不能因为“突出重点”而静默删掉原剧本内容。

每个视频段记录：

- `sourceSceneId`：来源场次 ID。
- `sourceBeatIds`：按发生顺序列出来源节拍 ID。
- `sourceDurationSeconds`：当前段所承接的剧本计划时长。
- `dramaticBeat`：这一段唯一的主要戏剧变化。
- `openingState`：第一帧前人物、物品和空间状态。
- `endingState`：最后一帧后必须成立的状态。

视频段 `durationSeconds` 应与 `sourceDurationSeconds` 一致。因自然语速或动作物理时长需要调整时，只允许小幅调整并保留说明；不得把 25 秒场景直接摘要为 13 秒。

## 拆分原则

- 一个视频段只承载一个主要戏剧变化，可以包含若干服务于该变化的连续动作。
- 地点、时间、主要人物组合或叙事目标改变时新建视频段。
- 一个完整对白交换无法在 15 秒内自然完成时，在反应、停顿或行动转折处分段，不在一句话中间截断。
- 重要台词前后的沉默、听者反应和动作结果都属于内容，不是可随意删除的空白。
- 同一动作跨段且确实需要运动和声音无缝延续时才使用 `continue`；普通戏剧切换使用 `cut`。
- 不在这一阶段决定故事板格数；先确认内容与时长，再进入 Shot 设计。

## 完整性检查

完成一场后对比：

1. 来源节拍集合与视频段 `sourceBeatIds` 并集完全一致。
2. 没有无意重复的节拍；有意跨段延续时明确说明重叠内容。
3. 视频段总时长与场次计划时长差异不超过自然表演允许范围。
4. 原剧本每句对白、旁白、关键动作和反应都有明确归属。
5. 每段的开始状态能承接上一段结束状态。

任何一项不满足时先修视频段计划，不生成故事板。
