# 资产验收清单

- 角色通用：一张 16:9 身份板中恰好包含正面完整全身、背面完整全身和放大的正面头肩近景三个面板；全身未裁切，三个面板的脸型骨相、五官、年龄、体型、发型、服装、材质、配色和识别点一致，纯净浅灰或白色背景、无文字标注，仅允许克制细分隔线，并检查与同项目其他角色的辨识度。
- 真人风格：额外排查塑料皮肤、磨皮、偶像脸、图库模特、CGI 和插画感，并检查真实毛孔、年龄纹理与自然轻微不对称。
- 非真人风格：按当前媒介检查线条或材质、形状概括、色块、阴影层级和风格一致性，不以真人毛孔或摄影感作为标准。
- 场景：空间结构清楚、时代地域和固定陈设一致、材质与光线可复用，无人物和单场剧情。多视图逐项核对同一门窗、工作台和光源的相对位置及视角反转；角色需要坐、站、绕行的位置必须有真实空间。几何冲突的图不得作为已采用空间主图或故事板构图依据；即使材质可用，也应保留为未采用参考并明确限制。
- 道具：轮廓比例、结构、材质与关键细节一致，无人物环境和文字。

自动检查失败只报告问题和重抽建议，不自动产生第二次费用。
全剧阵容检查还需两两比较脸型骨相、五官比例、年龄、发际线、肤色质感、体态、姿态与服装剪影；共享时代服装或统一摄影风格本身不等于撞脸。
