# GPT‑Image‑2 生成规范

模型必须由管理员显式标记 `imagePromptProfile: gpt-image-2`，不得从名称推断。角色生成固定一次请求、一个结果、高质量、2560×1440；渠道拒绝该尺寸时直接报告，不静默降质。提示词分为角色身份、当前风格、媒介质量、单张四视图版式和通用禁止项，不堆叠重复同义词。真人皮肤和相机约束只用于 `live_action`；二维、三维、插画、手工和图形风格使用各自媒介约束。

角色板必须是一张图内四个视角，不是四次生成。真人角色只使用风格文字，避免示例面貌污染演员身份；非真人媒介可把统一风格板作为 `style_reference`，但只能继承媒介、线条或材质、色块、阴影和配色，不得继承示例人物身份。场景和道具继续使用统一风格板。

多图输入必须逐张声明用途并按身份、服装、构图排序：身份参考只锁定授权人物的面貌、年龄感、肤色和体型；服装参考只锁定轮廓、结构、材质与配色；构图参考只控制版式。不得混合不同图片中的人物身份。无身份参考时直接使用完整选角描述文生图。
