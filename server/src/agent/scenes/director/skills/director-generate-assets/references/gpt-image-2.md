# 图片生成规范

使用管理员当前配置且具备所需输入能力的图片模型，不根据模型名称猜测，也不强制某个提示档案。每次请求只生成当前明确的一个身份媒体或素材参考；提示词分为稳定身份、当前风格、目标媒体用途和通用禁止项，不堆叠重复同义词。真人皮肤和相机约束只用于 `live_action`；二维、三维、插画、手工和图形风格使用各自媒介约束。

主要角色的 `face-closeup`、`body-front`、`body-back` 是同一权威角色下的互补媒体，不是三个角色，也不要求一次性全部生成。真人角色只使用风格文字，避免示例面貌污染演员身份；非真人媒介可把统一风格板作为 `style_reference`，但只能继承媒介、线条或材质、色块、阴影和配色，不得继承示例人物身份。场景和道具继续使用统一风格板。

多图输入必须逐张声明用途并按身份、服装、构图排序：身份参考只锁定授权人物的面貌、年龄感、肤色和体型；服装参考只锁定轮廓、结构、材质与配色；构图参考只控制版式。不得混合不同图片中的人物身份。无身份参考时直接使用完整选角描述文生图。
