# 章节式故事写作

## 私下规划，正文呈现

动笔前只在内部回答：主角此刻想得到什么，什么人或现实阻止他，哪一次选择使局面不可逆，后续事件如何由前一事件造成，结局让人物付出或获得什么。结构用于维持长文本一致性，不应作为最终文档的外壳。

## 章节职责

- 章节是一个完整的叙事运动：进入时有明确处境，离开时信息、关系、目标、风险或人物认识已经改变。
- 用 `# 作品名` 和 `## 第一章 章节名` 组织 Markdown；章节名可以简洁，但不要用“背景介绍”“人物设定”等策划标题。
- 章节长短服从内容。短篇不为形式凑章，长篇也不把每个动作拆成小节。
- 章节之间保留因果或悬念接力，让下一章来自上一章的选择、结果或未解决压力。

## 正文方法

- 关键事件写成场景：让人物在具体空间里行动、观察、说话、误解和承担结果；过场与重复信息才使用概述。
- 用可感知的物件、声音、距离、动作和身体反应承载信息，不用作者说明替人物完成情绪。
- 对白应包含目的、回避、试探、交换或压力；不同人物的措辞、句长和沉默方式要能区分。
- 内心活动只写当前感受、判断、记忆或选择，不连续解释人物小传和主题。
- 稳定使用同一视角与时态；需要切换时以章节边界和清楚的叙事信号完成。
- 反转必须改写前文细节的意义，而不是凭空补出未铺垫的信息。
- 结尾解决当前主要矛盾并留下人物后果或情绪回响，不使用总结中心思想的段落。

## 完稿检查

- 删除“故事讲述了”“本章主要”“人物弧光”“接下来进入”等方案腔。
- 删除连续的评价词、泛泛哲理、教学式解释和重复总结，改成动作、细节或对白。
- 检查每章是否真的改变局面，每个重大结果是否有可追溯原因，每个主要人物是否做过影响结果的选择。
- 检查全文能否作为小说直接阅读，而不是必须先理解制片流程、表格或内部术语。
- 借鉴作品时只借叙事功能和通用技法，不复制专有角色、标志性台词、名场面或连续情节链，也不仿写在世作者的独特个人文风。
