# 长篇改编方法

## 分层理解

1. 从目录、章节摘要和已有分卷摘要识别主线、主要人物、关键承诺与结局。
2. 只为当前改编问题检索相关正文，记录事件的原因、选择、结果及其来源位置。
3. 信息冲突时回到正文核对，不用摘要中的推断覆盖原文事实。
4. 先完成全书级取舍，再分章写正文；写完一章后核对它与前后章节的因果接力。

## 压缩原则

- 优先保留改变人物选择、关系、风险和结局的事件。
- 合并承担相同叙事功能的人物或事件，但不要把多次升级压成一句概述。
- 删除支线时补齐它原本承担的必要信息、动机或后果，避免主线突然跳步。
- 关键场面使用完整叙事，重复旅行、训练、调查和信息复述可以概述。
- 目标时长用于控制故事容量，不在文学正文中出现制片时长和镜头数量。

## 正文标准

- 使用 `# 作品名` 与自然的 `## 第一章 章节名` 组织 Markdown。
- 每章进入时有压力，结束时处境发生变化；章节不是原作内容的逐章摘要。
- 保留人物独立说话方式、关键选择和行动后果，让转折由前文铺垫兑现。
- 不写“改编思路”“保留情节”“删除支线”“本章功能”等幕后说明。
- 完稿后检查所有主要结果是否有原因、核心人物是否有可见选择、全文是否能脱离原作与制作说明独立阅读。
