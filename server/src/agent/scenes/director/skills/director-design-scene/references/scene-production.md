# 场景生产规范

场景母版先固定平面关系、入口出口、纵深层次、主要结构、年代地域、固定陈设、材质体系和基础光源，再说明远景、中景、近景可拍摄区域。

不要为完整展示而强制多视图母版。当前片段只需要一个空间方向时，可以采用清晰的主机位图；采用多视图时，每格必须能对应同一空间布局，内外反打不能简单复用画面左右关系。桌后座位、通道宽度和道具可达位置应满足剧本动作；若生成结果无法满足，修订机位或布局后再制作依赖它的预演与定妆帧，不以“只参考氛围”掩盖空间错误。

母版不出现人物或某一场的动作，不把临时天气、火灾、破坏、节庆布置等剧情状态写成永久空间属性。同一地点的昼夜或重大状态变化需要独立版本，并保留相同空间锚点。
