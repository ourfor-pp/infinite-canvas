# 导演方案

导演方案在理解故事之后、创作剧本之前确定本次改编如何取舍与表达。只维护 `direction/directing-rules.md` 和 `direction/visual-style.md` 两份权威文档：前者承载改编决策与导演规则，后者决定媒介、色彩、光线、材质和画面质感；更换视觉模板不得覆盖导演规则。

先读 `project.yaml`、用户当前要求、`story/` 和已有 `direction/`。外部故事有 `sources/` 时按任务检索相关原文，区分原始来源、已有转述与本次改编设想；不要把转述中的漏洞当成原作结论，也不要覆盖来源或为了制定方案先重写一篇小说。没有剧本时直接制定方案，不以剧本完成为前置；已有剧本时只读与本次修订有关的场景，核对方案变化会影响什么。

完整方案先确定下述“创作定位”和“核心导演意图”，再选择服务于这些决定的视觉与声画语言。用户只调色彩、风格或某项规则时，只读取必要上下文并修改对应部分，保留其他决定；不借局部修改重做整片或自动改写已有剧本。

成片画幅在导演方案阶段确定，以 `direction/directing-rules.md` 的摄影章节为唯一依据，明确写出方向与宽高比（例如横版 16:9、竖版 9:16），以及确有需要的画幅变化范围。优先遵循用户明确要求；缺少要求时结合发布用途与已有工程作合理决定并在方案中说明。方案保存即采用，不增加确认或锁定按钮；后续不得因场景、格数、参考图形状或工具默认值自行改变，只有用户要求修改或方案已明确的变化才允许调整。旧方案尚未写明时先核对用户要求和已采用画面，补入一致的决定；证据冲突才提出一个简短问题，不在每次生成时重新询问。

成片画幅约束预演、定妆帧和最终视频；风格板或角色身份板可按自身用途采用其他比例。风格板、身份板可以继续按各自用途采用横向版式，不能据此把竖版作品改成横版。

把视觉选择整理成一段连贯、可直接用于图片生成的整片风格描述，覆盖必要的媒介、色彩、光线、材质和镜头气质即可。明确维护 `mediumFamily`，并分别用 `characterRendering`、`sceneRendering`、`propRendering` 说明同一风格如何呈现三类素材。模型已经理解自然语言，不要为了填字段重复堆叠近义词，也不要把内部 Style DNA 逐项复述给用户。

优先读取当前 `direction/visual-style.md` 并复用有依据的既有视觉设定；新方案直接写入这份权威文档，不创建数据库风格实体或操作独立采用状态。导演风格选择或保存后立即采用，不存在额外确认步骤。Style DNA 用于参考图分析、跨素材一致性检查和高级微调：能从描述或参考图可靠提取时再维护，缺少依据的字段留空，不为了形式完整而臆造。

首次制定完整导演方案时，交付包括两份权威文档和一张可用的统一风格板。用户说“继续导演方案”“制定导演方案”即按此范围完成；除非明确只要文字或禁止生图，不要写完文档就结束，也不要再等待“风格图还没生成”的提醒。先检查已有 `referenceBoard` 与实际图片，适用则复用；缺失时用当前引擎图片能力生成，Codex 使用原生生图，保存到 `direction/references/style-board.<扩展名>`，再写回 `visual-style.md` 的 `referenceBoard`。实际打开检查风格是否一致；工具不可用或生成失败时报告具体缺口，不宣称完整方案已交付。局部规则修改不触发这项首次交付流程。

参考图分析和参考图生成只服务于统一整片视觉语言，不混入角色或单一场景的剧情细节。需要生成视觉参考时只建立一张横版统一风格板，在同一图片中展示中性人物、无人场景和中性道具；不得拆成三张图片。真人风格的毛孔、年龄纹理、真实镜头和禁止磨皮属于风格；二维动画的线条、色块和阴影层级也属于风格。脸型、骨相、体型、发型和身份识别点不属于风格。

修改导演规则不影响视觉参考板；修改风格描述或 Style DNA 时保留当前 `referenceBoard` 和图片。实际查看旧图，判断它是否仍符合调整后的视觉方向：整理文字且旧图仍适用时继续沿用；存在具体差异时说明差异并标记待复核，不把文字变化等同于必须重新生图。只有用户授权生成或上传的新图已经成功落盘后才替换当前引用；生成失败仍保留旧图。用户明确要求移除时才删除引用或归档图片，不为“待更新”把当前图移入历史目录或回收区。

导演规则写入 `direction/directing-rules.md`：

- `positioning`（创作定位）：根据故事、目标时长和用户约束确定题材、类型、基调、时代地域、目标观众和本次核心命题；作为首章，不以复述梗概代替表达选择。
- `intent`（核心导演意图）：写清本次改编的保留项与可调整范围、主要人物的目标和相互冲突的理由、叙事视角与观众信息、从开场吸引到结尾兑现的情绪走向。可用三级标题组织这些内容，不另建定位或改编文件。
- `photography`：镜头稳定性、距离、空间关系、视点和运动原则。
- `performance`：演员的表演尺度、反应、停顿、喜剧或情绪表达原则。
- `pacing`：Shot 停留、切镜密度、留白、转场和信息释放原则。
- `sound`：对白、环境声、动作声和音乐的使用边界。
- `prohibitions`：全片统一禁止的陈词滥调或无意义做法。

“核心导演意图”应作出当前作品的具体选择：

- 说明要保留的核心事件、关系、主题或结局，以及可删减、合并、重排或补充的内容及理由。区分来源事实与改编设想；对原文疑点说明影视处理中如何理解或补足因果，不擅自改变用户明确要求保留的内容。
- 说明人物各自想得到什么、为何互相阻碍，以及重复冲突将如何改变信息、策略、代价或关系；为编剧确定矛盾依据，不代写完整剧情和对白。
- 选择跟随谁、观众比人物多知道或少知道什么，以及悬念依靠什么成立；不预设所有题材都必须隐瞒真相或采用反转。
- 结合目标时长确定开场的具体观看理由、发展中的变化与结尾回报，取舍次要内容。开场应指出让观众好奇、共情、期待或愿意停留的情境与行为依据，不只写“交代背景、建立关系、营造气氛”；不强制以危险、反转或固定秒数开场，也不按生成窗口分配剧情。

摄影、表演、节奏和声音应说明所选手段服务于哪项具体叙事目的。区分用户明确约束、整片基础风格与可随情境变化的表现尺度；需要变化时说明用途及保持统一的依据，不把“克制、柔和、庄重”等基调扩张为所有场景同一强度。悲喜并置、夸张或留白是否适用，取决于它是否深化人物体验、保留行为后果，不仅凭情绪名称一律禁止或强制使用。动画项目按表达需要确定动作的预期、落差、反应与夸张尺度，不以 Q 版或水墨等造型词代替表演设计；安静或慢节奏可以成立，但应说明留白承载的信息或情绪。避免只写“电影感、情绪真实、节奏紧凑”等可套用任何作品的评价，也不要强行为每类作品添加喜剧或音乐。

保存完整方案或修改人物、结构、叙事方向前，阅读 [导演方案决策检查](references/treatment-review.md)，检验关键选择与替代行动、新增设定的因果影响、开场观看理由以及表现尺度；修正发现的问题后再保存，不以章节齐全或写了“递进、信任、代价”作为通过依据。局部视觉修改只检查受影响的表达约束，不强制重审整部故事。缺项按用户意图作合理决定并先交付可修改方案，不为形式完整堆字段或重复询问已确定的方向。方案保存即为当前依据，不新增确认或锁定门槛；已有剧本受影响时说明涉及的场景与原因，只在用户授权的剧本修订范围内继续修改。
