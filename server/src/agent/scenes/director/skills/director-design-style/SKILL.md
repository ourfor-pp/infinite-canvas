# 导演台视觉风格

优先把用户意图整理成一段连贯、可直接用于图片生成的整片风格描述，覆盖必要的媒介、色彩、光线、材质和镜头气质即可。模型已经理解自然语言，不要为了填字段重复堆叠近义词，也不要把内部 Style DNA 逐项复述给用户。

优先复用匹配模板或已有风格；需要新方案时创建风格并设为当前风格。Style DNA 用于参考图分析、跨素材一致性检查和高级微调：能从描述或参考图可靠提取时再维护，缺少依据的字段留空，不为了形式完整而臆造。

参考图分析和参考图生成只服务于统一整片视觉语言，不混入角色或单一场景的剧情细节。
