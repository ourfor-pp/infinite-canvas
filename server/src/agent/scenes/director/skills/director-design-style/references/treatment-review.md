# 导演方案决策检查

这些检查用于检验本次方案，不是输出模板。只检查当前作品实际依赖的机制；观察式、抒情或非线性作品可以由体验、发现与意象变化组织，不强塞对抗、悬念或三幕结构。保留明确的用户要求，未获支持的推断标为改编选择。

## 关键选择是否成立

对决定结局或关系转折的选择，结合人物当时知道的信息、目标、能力、约束和价值取向，追问“为什么此刻这样做”。再考虑一个当时确实可行、代价更低的替代行动：等待、解释、求助、退出或其他符合情境的做法为什么没有发生？不要求人物理性最优，但冲动、恐惧、执念、误解等原因应有可由剧本呈现的行为依据，不能只用“关系破裂”“命运如此”替代。

新增证人、证据、能力、援助、限制或控制局面的手段后，重新检查它是否已解决原来的阻碍。若仍保留原来的激烈行动或结局，说明剩余压力从何而来；不要为了既定结局让人物忽略新事实，也不要临时添加无铺垫的危险来堵住替代方案。无法自洽时，在允许的改编边界内调整设定或转折。

人物矛盾可以保留多义性，但不能靠作者解释才成立。导演方案确定冲突的依据与选择代价，具体现场行动、对白和细节交给剧本；不能把决定方向能否成立的缺口全部留给编剧补。

## 观众为什么继续看

检查开场提供了什么具体体验或期待，以及人物哪种行为让观众开始在意。若删掉背景解释后没有任何观看理由，应明确一个与后文有关的情境、关系张力或发现过程，不用无关刺激制造钩子。

对关键段落问“前后改变了什么，为什么会带来下一步”。反复发生的事件是否改变了策略、信息、代价、关系或观众理解？换标签而可互换的段落尚未形成发展。结尾的情绪回报应能追溯到此前的行动与积累；非因果叙事则检查感知或意象的变化，不机械套用冲突升级。

## 表达规则是否帮助作品

对方案中的重要声画限制，检查它保护什么效果，是否误伤人物表演、节奏变化或情绪复杂性。区分“避免消解伤害”与“禁止任何幽默”等不同要求。固定媒介和身份仍允许有目的地改变构图、运动、对比、声音密度与表演强度；具体变化应服从作品方向和用户约束。

删去只换题目就能套用的评价句，留下可指导取舍的判断。检查重点是选择是否有依据，不以条目数量、术语或篇幅证明质量。把修正落实到现有“核心导演意图”和相关声画章节，不新增评分表、审批门槛或第三份权威文档。仍需剧本试写验证的地方如实说明，不能宣称完成检查就保证成片好看。
