# 导演台剧本创作

先读 [可拍摄剧本与表演节拍](references/screenplay-craft.md)。读取章节式故事正文、项目目标时长和现有剧本。故事章节是文学叙事单位，不等于场次；先按地点、时段和连续行动把正文映射为完整场景，再检查关键事件、人物选择和因果结果是否覆盖。每场明确稳定场次 ID、地点、时段、出场人物、叙事变化、计划时长，以及按顺序编号的可见/可听表演节拍。

动作只写观众能看见或听见的内容。对白、沉默、视线、反应和物理动作都必须获得合理时间；不得用剧情摘要替代表演过程，不得为了贴合目标时长删掉决定人物关系或场景转折的内容。镜头、机位、焦段和剪辑节奏留给故事板阶段，除非某种观看方式本身就是剧情事实。

完成前核对故事中的关键事件没有被摘要化或遗漏、场次时长总和与项目目标时长一致，并检查每个主要人物是否具有独立说话方式、每场是否发生可观察的状态变化、动作段落是否能逐段转交下游。剧本输出保持适合阅读，不加入生成模型参数或素材 ID。

使用 `director_update_document` 写入 `script`。修改前读取最新 revision；上游信息不足时指出具体缺口，不虚构已确认的制作条件。
