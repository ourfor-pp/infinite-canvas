# 标准分场剧本写作

## 职责边界

剧本负责人物、冲突、动作、对白、沉默与反应，不负责生产拆解或把场景预先剪成 Shot。使用完整场景表达；只有蒙太奇、画面文字、画外音或观看方式本身构成叙事事实时才写必要技术说明。

故事章节是读者的文学阅读单位，场次是可连续表演的时空单位，两者不能按标题一一复制。一个章节可以拆成多个场次；相邻章节若处于同一地点、时段和连续行动中，也可以落入同一场。改写前依据导演方案和用户约束识别必须保留的事件、选择、揭示和后果，完成后逐项核对；已允许删减或合并的内容按其戏剧功能处理，不把来源中每个事件都变成必须拍摄的项目。

## 正文格式

作品名使用一级标题，场景使用二级标题。场景标题写清内外景、地点和时段；场景编号可以保留，但不使用内部数据库 ID。正文只呈现动作、对白和必要的声音信息：

```markdown
## 2. 内景 · 会议室 · 日

会议室里还有零星交谈。林慕径直走到白板前，把需求文件拍在桌面上。声音落下，交谈停止。

林慕没有立刻说话。她扫过每个人，等最后一台电脑合上。

**林慕**

开周会前，我先把丑话说在前面——这版需求，上线前还要再压三天。

小鹿低头假装记录，身体向阿凯偏过去。

**小鹿**（低声）

灭绝师太今天心情好像更差了。

**阿凯**

嘘。

林慕的视线停在两人身上。小鹿立刻坐直。
```

章节标题不得直接复制成场景标题。一个章节可以拆成多场；相邻章节若发生在同一时空和连续行动中，也可以合并为一场。

说话者必须用 Markdown 加粗明确标识，角色名与台词之间保留空行。语气或发声方式写在加粗角色名之后，例如 `**小鹿**（低声）`；不要把整句台词加粗，也不要使用只靠单换行成立的“角色名\n台词”，因为标准 Markdown 会把它们合并成同一段。

## 写作检查

- 每个动作段只描述可观察事实，避免人物小传、解释性心理和抽象评价。
- 动作段不要写“心里相信”“想起”“觉得”“知道”“素来如何”“这才明白”等内在结论；改写成视线、停顿、回避、误认、身体反应、说出口的话或随后的选择。旁白明确承担叙事功能时除外。
- 不写“最后一句是对某人说的”“观众这才知道”“这场戏说明”等作者解释；通过人物朝向、行为和场面关系让含义成立。
- 每场提供具体的叙事或体验作用，可以是行动变化，也可以是关系积累、氛围体验或意象发展；不能仅用换位置或插入空镜证明有内容。
- 让对白通过措辞、句长、停顿和回避体现人物，不用括号堆砌表演指令。
- 为对白前后的反应留时间；一场戏不能只有说话人，没有听者行为。
- 关键动作写清开始、过程和结果，不使用“二人争执”“众人震惊”等摘要跳过表演。
- 剧本修订允许按导演方案和用户要求删改、合并旧台词、旁白、动作与场景；检查必要的因果、信息和情绪积累是否仍成立，不因“已经写过”保留冗余。后续制作拆解应忠实覆盖当前采用剧本，不能反过来要求编剧无损保留所有旧稿。
- 不写“场景变化”“人物目标”“节拍”“预计时长”等分析标签；这些属于独立制作拆解。

## 把方向写成现场的戏

冲突或目标驱动的场景中，人物为当下想得到的结果采取行动，对方的回应或环境变化影响下一步做法；不要写成轮流说完台词再做装饰动作。障碍可以来自他人、环境、自身犹豫或价值冲突，不必新增反派。人物采用或改变策略时，写出实际尝试以及它对他人判断、可选行动或局面的影响；不能只让人物宣布计划，再由旁人自行完成预期结果。策略可以失败、被阻止、放弃或尚未执行，但这些状态及其原因应在叙事中可辨认，不强制每个计划成功。观察、抒情与日常段落可以围绕共同活动、感知和关系积累展开，不强制套用攻防节拍。

关键选择必须在正文里成立：依据人物当时知道的信息、处境和此前行为，呈现他为何采取或放弃某种做法。即使导演方案已解释动机，也不能省掉支撑它的现场过程；不让角色突然用一句自我分析替作者补逻辑。可行的低代价选择未被采用时，应有性格、误解、压力或价值取向的行为依据，不要求人物最优决策，也不靠临时追加危险堵住其他选择。

对白首先是人物在关系中的行为。判断他此刻说给谁、想争取或维持什么，对方如何接住、拒绝、误解或转移；试探、回避、安慰、分享、讨好和施压都可以成立，不强制每句藏潜台词或制造冲突。人物语言随对象、身份和压力改变，不只靠口头禅区分。已由画面、行动或前文充分传达的信息，除非重复本身改变关系或意义，否则不再解释一遍。跨台词、动作与场次检查同一信息是否反复交代；补了表情或小动作，不代表增加了叙事、关系或体验内容。可以让一个有目的的行动同时承担信息与人物表达，合并无新增作用的说明，但不为追求密度删掉必要的理解时间和情绪余韵。

按实际视线、距离、遮挡、声音与在场情况区分人物掌握的信息和观众看到的信息。离场者不能自动知道刚发生的事，观众专属揭示不能成为人物判断依据；反过来，人物明确看到的证据也不能在下场被忘掉。不需要输出信息表，但正文应足以判断谁知道什么及何时知道。

节奏来自内容的变化：动作有意图、过程和结果，听者的反应可以通过继续手里的事、改变距离、打断或没有回应来表达，不给每句台词机械配一个停顿、点头、转头或流泪。沉默要让等待、回避、发现或感受实际发生；按作品需要选择对白、动作和沉默的比例，不以少对白等同于高级，也不以密集对白等同于内容丰富。动画的夸张与悲喜并置服从人物和后果，不把造型风格当成表演。

## 开场与场间衔接

将导演方案的观看理由落实为可感知的情境、行为或发现，让观众对人物产生在意、好奇或某种体验期待；不能只靠背景说明和“建立关系”的概括。开场不必有危险或反转，也不规定必须在固定秒数出现钩子。

安排场景时检查上一场留下的后果、未解问题、承诺或期待如何进入下一场。转场也可通过情绪、意象或主题对照产生联系，不要求所有场次都直接因果相连；非线性叙事仍应控制信息，使有意保留的疑问与无意造成的混乱可以区分。进出场时机以这场戏需要观众经历的内容为准，省略无作用的重复到达、寒暄、往返和总结，不把必要的反应与余韵当成拖沓。结尾的回报应能追溯到此前的行动或体验积累，不能仅靠流泪与配乐宣布感动。

## 时长与戏剧结构

目标时长是内容容量约束，不是让正文显示秒数。写作前按开端、发展、转折和结局的实际重要性分配内部容量；对白密集场景要给说话、停顿和听者反应留空间，动作场景要给动作的准备、执行和结果留空间。若预计超出目标，优先删除重复解释、重复证明、无后果的往返和已经完成后的再次总结，不压缩不可缺失的决定与结果。若明显不足，补充人物为关键选择付出的过程，不用景物描写或重复对白凑量。

依赖冲突递进的相似事件连续出现时，应改变核心条件，例如：阻力更强、信息发生变化、失败代价增加、人物策略改变或关系进一步恶化。只更换外形、地点、道具或台词措辞，不构成递进。相似行动产生不同结果时，正文应提供可感知的区别，例如先前积累、条件变化、行动方式或对手反应，不能仅将结果换成成功、失败或彻底结束。依据可以提前建立或按叙事设计稍后揭示，不必用台词讲解机制；有意保留的未知不等于所有因果都必须解释，但不能用未知掩盖关键结果缺乏依据。

重大决定必须有因果阶梯：此前出现可观察的事实或压力，人物对其作出反应，新的行动改变局面，最终决定由这些累积自然产生。若观众只能用“剧情需要”解释转向，应补足过程或调整决定。

人物已经亲眼看见或亲耳听见的事实会成为后续场景的既有信息。后文不得让人物无缘无故当作该事实不存在；若人物仍作出相反判断，必须具体呈现以下至少一种依据：证据本身可被合理伪造、人物坚持与事实不同的价值原则、可信关系施加压力、人物因既往经验产生误判，或新的事实改变了证据含义。不能用“耳根软”“被挑唆”“心里仍不信”等作者结论替代过程。

在导演方案确定的改编边界内，可以保留原作事件和结局而调整其视听表达；改变根本动机或核心解释应先按当前授权修订方向，不由编剧静默决定。优先保留事件承担的戏剧功能，再为人物重建清楚的现场证据、选择和代价。例如，冲突可以从“是否看见事实”转化为“看见事实后如何解释、是否接受手段、愿意承担什么后果”，避免角色为了抵达既定结局而突然失去判断力。

判断场景价值时同时考虑叙事推进、关系积累、情绪余韵与感知体验。若删除后这些均无实质损失，可合并、删减或重写；不为通过检查给每场硬加一次冲突、转折或新信息。

## 质量标准

剧本应让读者仅凭正文就能回答：谁在何处、先做什么、谁看到并如何反应、哪句话在何种行动中发生、这场戏带来了什么变化或积累、有重大决定时为何在此刻发生。若无法回答，先补剧本，不用制作标签掩盖缺失的戏。

## 提交前反证

更新正文前，不复述检查结果，只在内部逐项反证草稿：

- 找出关键选择及可行替代，向前追溯正文中的事实、压力、反应和行为依据；检查人物是否借用了只向观众披露的信息，不能引用导演方案为正文缺口辩护。
- 对承担递进的相似事件比较策略、信息、代价与关系变化；对有意重复的意象或日常行为检查语境与感受是否积累，不为重复本身一律删减。
- 检查开场的期待、场间承接与结尾回报；尝试删除可疑段落，同时评估因果、关系和体验损失，不只以情节是否推进判断价值。
- 跨台词、动作和场次检查重复信息；移除说明与装饰小动作后，确认是否损失实际内容，保留有关系、理解或情绪作用的重复与沉默。
- 追踪重要策略的尝试及其影响，或未能实施的原因；比较相似行动的不同结果能否由正文中的区别支撑，不以计划宣言或结果断言代替过程。
- 按真实对白、停顿、反应和动作估算整体容量；明显偏离目标时调整内容，不用字数或一句“面向目标时长”代替估算。
- 搜索动作段中的心理结论和作者解释，将其转换为可听见、可看见的表演。

完成这些修订后才保存剧本文件。最终回复只报告实际写入结果，不把规划中的目标当作已经实现的质量证明。
