# 可拍摄剧本与表演节拍

## 职责边界

剧本负责人物、冲突、动作、对白、沉默、反应和场景时长，不负责把场景预先剪成 Shot。使用完整场景表达；只有蒙太奇、画面文字、画外音或观看方式本身构成叙事时才写必要技术说明。

故事章节是读者的文学阅读单位，场次是可连续表演的时空单位，两者不能按标题一一复制。一个章节可以拆成多个场次；相邻章节若处于同一地点、时段和连续行动中，也可以落入同一场。改写前先列出故事中不可丢失的事件、选择、揭示和后果，完成后逐项核对。

## 场次结构

每场使用稳定且可读的结构：

```markdown
## 场 S002 · 晨会立威（内 / 日，计划 25 秒）

**地点**：会议室  
**人物**：林慕、小鹿、阿凯、项目组  
**场景变化**：从散漫交谈变为全场服从林慕的节奏。

**节拍 S002-B01（约 5 秒）**  
会议室里还有零星交谈。林慕径直走到白板前，把需求文件拍在桌面上。声音落下，交谈停止。

**节拍 S002-B02（约 8 秒）**  
林慕没有立刻说话。她扫过每个人，等最后一台电脑合上。

林慕：开周会前，我先把丑话说在前面——这版需求，上线前还要再压三天。

**节拍 S002-B03（约 6 秒）**  
小鹿低头假装记录，身体向阿凯偏过去。

小鹿（低声）：灭绝师太今天心情好像更差了。

阿凯：嘘。

**节拍 S002-B04（约 6 秒）**  
林慕的视线停在两人身上。小鹿立刻坐直。林慕转回白板，继续写下期限。

林慕（旁白）：那年我以为，只要跑得够快，就不会被任何人丢下。
```

场次 ID 与节拍 ID 在同一剧本 revision 内保持稳定。修订内容时优先保留 ID；插入新节拍使用新的编号，不把两个不同表演变化强行合并成一个节拍。

## 写作检查

- 每个动作段只描述可观察事实，避免人物小传、解释性心理和抽象评价。
- 每个节拍产生一个可辨认变化：位置、信息、情绪、权力、目标或关系至少一项发生变化。
- 让对白通过措辞、句长、停顿和回避体现人物，不用括号堆砌表演指令。
- 为对白前后的反应留时间；一场戏不能只有说话人，没有听者行为。
- 关键动作写清开始、过程和结果，不使用“二人争执”“众人震惊”等摘要跳过表演。
- 场次计划时长必须大于等于节拍时长之和；全片场次总时长应接近项目目标时长。
- 不为追赶剧情删掉已建立的台词、旁白、反应或动作结果；需要提速时先判断能否合并重复信息。

## 质量标准

剧本应让下游仅凭文本就能回答：谁在何处、先做什么、谁看到并如何反应、哪句话在何种行动中发生、场景最后与开始相比改变了什么。若无法回答，先补剧本，不进入视频段规划。
