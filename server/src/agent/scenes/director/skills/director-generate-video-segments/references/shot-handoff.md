# 镜头到制作任务的交接

镜头设计定义完整表演；任务定义单次生成目标；时间线片段定义实际采用范围。用 `shotIds` 建立关联，允许一镜跨任务、多镜共任务、反应单独生成。

`task.md` 保存任务时长、显式输入和依赖，`video-prompt.md` 保存原样提交正文。H3 具体格式见 media-generation Skill 的官方提示规则；每个 reference 索引必须对应预检列出的实际输入，不假设程序暗中追加风格或身份参考。

图片可选；如确需首帧引导，显式设置 `useOpeningGuide: true`，以预检的实际裁切信息检查构图。故事板结构仅作为辅助计划，实际切点通过成片取样核对。

原生续接依赖当前上游状态和完整运行时身份；不得混用基础版与加速版状态。引用过期时报告具体依赖，按用户授权决定重做范围。

检查每次输出的实际时长、首尾动作、说话人和原声。输出保留在任务目录；生成成功不自动追加剪辑片段。
