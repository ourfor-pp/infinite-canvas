# 导演台角色设计

读取当前角色、同项目其他角色和视觉风格，把剧情人物转化为可跨镜头复用且不会脸盲的视觉身份与声线。先读 [角色生产规范](references/character-production.md)。

- `character.md` 的“剧情身份”：保留身份、关系、身世、性格、人物弧光和剧情用途，绝不直接作为生图提示词。
- `character.md` 的“视觉设定”：只写肉眼可见且在当前基础造型中稳定不变的年龄感、体态、脸型五官、肤色、发型、服装、鞋履、配饰、材质、标志性色彩和识别特征；不写姓名、性格、关系、身世、动作、场景、情绪变化或剧情事件。
- Frontmatter `designProfile.identityAnchor`：从视觉描述中压缩出最少但足以保持身份一致的锚点，不写前后期变化、受伤状态或情绪表演。
- `visibleAgeCues`、`bodySilhouette`、`posture`：分别保存可见年龄纹理、远景全身剪影和稳定姿态，不能互相替代。
- `distinctivenessSummary`：说明该角色相对当前阵容最有辨识度的脸部、体态和造型组合，不写性格标签。
- Frontmatter `designProfile.facialIdentity`：结构化保存脸型、骨相、眉眼、鼻唇、肤色、发际线和非对称识别点；未知项留空，不用审美套话补齐。
- 不同阶段的服装、伤势和状态应作为后续独立造型版本处理，不能用箭头或剧情顺序混入基础身份。
- 不在角色主档决定真人、动画、水墨、三维等媒介，也不写摄影、线稿、渲染、光线或后期；这些全部由 `direction/visual-style.md` 负责。最终图片提示的角色身份段只从上述结构化字段取值，媒介与渲染段则显式读取当前视觉风格。
- 声音提示词只写入 `voice/sound.md` 正文，中性试听台词写在该文件 Frontmatter 的 `sampleText`；最多保留一个 `voice/reference.*`，当前结果为 `voice/primary.*`，不要在主档重复声音提示词。

基础图像提示词写入 `identity/prompt.md`。正文必须是能够原样发送给当前图片模型的完整最终提示词：同时写清当前视觉风格、同一角色可观察的身份与体态、基础服装和识别点，以及一次生成一张横版 16:9 三栏身份板的完整输出要求。三栏依次为完整正面全身、完整背面全身和放大的正面头肩面部近景；同一身份、体型、发型、服装和媒介风格保持一致，并明确浅色无内容背景、无文字、无标注、无额外人物。不得依赖服务端补写版式、风格或禁止项。

采用的项目内图片在该文件 Frontmatter 的 `references` 中显式声明，例如 `- path: direction/references/style-board.webp`、`purpose: style_reference`、`label: 视觉风格`；只声明这一次确实需要发送的参考。用户上传的身份、服装或构图参考放 `identity/inputs/`，并在提示词正文逐张说明用途。真人角色是否采用含人物的统一风格板由当前风格和身份污染风险决定，不要机械添加。当前唯一权威结果为 `identity/primary.*`，不得把三栏拆成三个生成目标或三张媒体。持续造型或状态使用 `variants/var-NNN-slug/`，其中 `variant.md` 说明变化及适用场次，`prompt.md` 同样必须是可原样发送的完整最终提示词，输入放 `inputs/`，当前结果为 `primary.*`。只有剧本使用位置表明变化会跨视频段持续存在或缺图会破坏连续性时才创建变体。

先用 Glob/Read 列出并读取全部角色主档做阵容对照，确保主要角色在脸型骨相、体态比例、发型轮廓、服装剪影、年龄痕迹与自然识别点中至少三组明显不同，再用 Edit 修订对应 `character.md`。人脸与人体差异是所有媒介的通用身份规则；毛孔、真实相机、线稿、色块或三维材质不是角色身份，只能来自风格。完成角色设计不等于生成媒体；除非用户明确要求生成，否则不要调用生成工具。原文在性别、年龄或关键服饰上冲突时列出冲突并询问，不自行选择。
