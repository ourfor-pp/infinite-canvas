# 导演台角色设计

读取角色、剧本依据和当前视觉风格，补充年龄感、体态、五官、发型、服装、配饰、标志性色彩、身份一致性锚点与声线。描述必须可见、可听、可复现。

使用 `director_update_asset` 更新设定。原文在性别、年龄或关键服饰上冲突时列出冲突并询问，不自行选择。
