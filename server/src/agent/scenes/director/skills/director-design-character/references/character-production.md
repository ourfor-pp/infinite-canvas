# 角色生产规范

角色档案回答“他是谁”，视觉设定只回答“镜头看见什么”，身份锚点只保留跨镜头必须稳定的少量特征，声音设定单独描述音色与表演范围。

基础造型应固定年龄感、体态比例、脸型五官、肤色、发型、主服装结构、鞋履、材质、主辅色和一至三个识别特征。姓名、关系、职业故事、人物弧光、性格形容词和剧情行为不能进入图片提示词。剧情阶段的换装、伤势、污损和情绪是独立状态版本。

面部身份使用可观察结构，不使用“好看、英俊、清秀、剑眉星目、鹅蛋脸美女”等可互换套话。按剧本证据填写脸部宽长比、额头与颧骨、下颌和下巴、眉形、眼型与眼距、鼻梁与鼻头、唇形和嘴角、肤色质感、发际线、痣疤或轻微不对称。四视图中的脸较小，身份锚点优先选择远看仍可辨认的脸型、发际线、眉眼轮廓、发型、体型、服装剪影和高辨识度标记。

设计单个角色前先读取当前项目全部角色，建立简短阵容对照。主要角色之间在以下五组中至少三组明显不同：脸型骨相、体态比例、发型轮廓、服装剪影、主辅色与识别点。若两个角色只靠姓名或性格区分，先修订视觉设定。不要为了差异化改变剧本已经明确的年龄、族群或关键服饰；缺失部分选择与现有阵容不冲突的合理方案。

四视图是同一张横版图内的正面、左侧、右侧和背面四个完整等高全身 A‑Pose。使用纯白无影背景与中性光，不加名字、标题、标线、边框、环境或道具。
