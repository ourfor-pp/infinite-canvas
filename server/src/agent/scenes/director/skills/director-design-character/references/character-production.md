# 角色生产规范

角色档案回答“他是谁”，视觉设定只回答“镜头看见什么”，身份锚点只保留跨镜头必须稳定的少量特征，声音设定单独描述音色与表演范围。

基础造型应固定年龄感、可见年龄纹理、体态比例、姿态、脸型五官、肤色、发型、主服装结构、鞋履、材质、主辅色和一至三个识别特征。姓名、关系、职业故事、人物弧光、性格形容词和剧情行为不能进入图片提示词。剧情阶段的换装、伤势、污损和情绪是独立状态版本。

面部身份使用可观察结构，不使用“好看、英俊、清秀、剑眉星目、鹅蛋脸美女”等可互换套话。按剧本证据填写脸部宽长比、额头与颧骨、下颌和下巴、眉形、眼型与眼距、鼻梁与鼻头、唇形和嘴角、肤色质感、发际线、痣疤或轻微不对称。身份板右栏的面部近景负责稳定脸部身份，左栏正面与中栏背面全身负责稳定体型、姿态、发型轮廓、服装剪影和高辨识度标记。

设计单个角色前先读取当前项目全部角色，建立简短阵容对照。主要角色之间在以下五组中至少三组明显不同：脸型骨相、体态肩颈与身材比例、发型和发际线轮廓、服装剪影与材质、年龄痕迹和自然识别点。每个主要角色至少有一个稳定脸部结构锚点、一个远景剪影锚点和一个自然识别点。若两个角色只靠姓名或性格区分，先修订视觉设定。不要为了差异化改变剧本已经明确的年龄、性别表达、族群或关键服饰；缺失部分选择与现有阵容不冲突的合理方案。

“白嫩、清秀、精致、俊朗、美女、硬朗、剑眉星目”不能单独承担身份区分；若使用，必须紧跟可观察的宽长比、骨骼转折、五官间距、表面色阶或不对称特征。身份辨识来自具体结构、年龄痕迹和自然差异，不来自堆叠审美形容词。毛孔、摄影真实感、赛璐璐线条、三维材质等呈现方式属于视觉风格，不得写入角色身份。

主要角色默认只规划一张身份板媒体，不规划三张图片。身份板固定为横版 16:9 的三个并排纵向面板：左栏完整正面全身，中栏完整背面全身，右栏放大的正面头肩面部近景；三栏保持相同年龄、体型、脸部、发型、基础服装、材质和媒介风格。背景使用纯净浅灰或白色，只允许克制的细分隔线，不出现额外视角、剧情动作、环境、文字或标注。配角仍可使用同一单图版式；路人或人群只有确实需要跨镜头保持身份时才建立独立资产。
