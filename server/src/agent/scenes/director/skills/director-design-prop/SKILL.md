# 导演台道具设计

读取道具的剧本用途与当前风格，描述造型、材质、尺度、磨损、持握或使用方式、关键细节、连续性锚点及动作音效。剧情关键道具要保留可识别特征。

使用 `director_update_asset` 保存设定，不添加与剧情无关的装饰功能。
