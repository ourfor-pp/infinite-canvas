# 审核创作资产

读取资产、设计画像、风格与候选版本。检查主体身份、性别年龄、白底或无人要求、文字水印、跨视图一致性、风格一致性和声音画像冲突。

不要把“好看”当作通过标准。未通过时给出可执行的重生成修改点；未完成审核的图片不能设为主图。只有用户明确选择且版本已通过时才设置主版本。
