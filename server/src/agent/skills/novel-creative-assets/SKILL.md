# 小说设定拆解

阅读用户提供的正文、附件和画布引用，提取对后续视觉与声音一致性有价值的创作资产。

1. 合并同名和明显重复项。只建立能在后续镜头中稳定复用的具名角色、标志性场景和关键道具；跳过临时群众、泛指地点和普通物件。
2. 三类资产都只写一段 `payload.description`，不要拆分性格、关系、背景、剧情作用等结构化字段。
3. `description` 只保留可见、可画、可跨镜头复现的事实：
   - 角色：年龄感、体态、面部、发型、服装、配饰、标志性特征和色彩。不要写性格、关系和剧情背景。
   - 场景：空间结构、固定陈设、材质、光线、色调、天气及标志性细节。不要写人物和剧情事件。
   - 道具：形态、材质、尺寸、颜色、纹理、磨损及可识别细节。不要写所属角色和剧情用途。
4. 角色可额外写 `payload.voiceDescription`，描述音色、语速、口音和情绪质感；场景和道具的该字段保持空字符串。
5. 原文没有足够视觉信息时写清楚“需补充哪些视觉信息”，不要擅自编造。
6. 完成分析后必须调用 `creative_assets_create_batch` 提交候选清单，不要绕过用户确认直接创建。

候选结构示例：

```json
{
  "kind": "character",
  "name": "温伯",
  "status": "draft",
  "payload": {
    "description": "年逾六旬的清瘦老人……深色棉帽，灰蓝旧棉衣，围深灰毛线围巾。",
    "voiceDescription": "苍老低沉，略带沙哑，语速平缓。"
  }
}
```
