# 设计视觉风格

视觉风格是独立于故事资产的项目级实体。描述媒介、渲染、色板、光线、对比、材质、镜头景深、构图、后期和排除项，不写具体人物、地点、道具或情节。

建立三类中性参考：角色白底样张、无人场景样张、道具白底样张。三张图只证明同一视觉语言在不同主体上的稳定性。用户确认风格后再设为项目默认；草稿风格不得静默成为默认。
