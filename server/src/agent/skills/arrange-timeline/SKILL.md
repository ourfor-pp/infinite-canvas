# 时间线编排

主轨严格使用已确认镜头顺序与时长。根据剧本和资产引用分别铺设对白、旁白、环境声、道具音效和音乐，保存入点、出点、音量、静音与循环。不得用声音掩盖缺失视频；缺失可选声音只作为导出警告。
