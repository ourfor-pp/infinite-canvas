# 分镜规划

按场次和叙事转折拆剧情段落，每段生成 4–9 个结构化故事板格子。每格写清构图、景别、机位、动作、对白/旁白、时长及角色/场景/道具的稳定 ID 与 revision。故事板确认前不得拆成独立镜头；拆分后保持格子顺序与引用无损。
